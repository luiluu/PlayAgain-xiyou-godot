## 使用方式

在 Mac 调用工具的 `status` 查看状态，`list` 加游戏内相对目录列文件，`read` 加相对文件路径读回 Base64 内容、字节数和 SHA-256。原始字节保真，避免 Windows 文本编码导致中文或脚本损坏。

工具从[来源登记](../../00_项目管理/来源登记.json)取得虚拟机 UUID 和 Windows 路径。调用时 PD Windows 需要处于运行状态；不自动启动、重启、关闭虚拟机或游戏。

读取不等于固定基准。Steam 后续更新会改变安装目录，应保存实际使用文件的来源、BuildID、SHA 与审计快照。文件证据见[本轮原版访问记录](../../00_项目管理/验证与备份/20261012_Godot部署/pd-original-access.json)。
