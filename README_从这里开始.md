## 保存资料的规则

1. 原版安装文件先放 `01_再刷一把/01_待接收原版/`，核对后才能登记为基准。
2. 西游 MOD 的新资料继续存入原资料库；本分类引用唯一原件。
3. Godot 重制新增设计、工程和素材放入 `03_再刷重制_Godot/` 的对应目录。
4. 每项现行计划、状态、来源与规范只有一份原件，通过链接引用。历史副本仅留在备份中。
5. 实际完成后更新状态和变更记录，记录文件校验、验证与未完成项。

`02_再刷西游/现有资料库` 是目录链接。编辑其内容会修改旧资料库中的原件，不能把链接目标当作重复文件删除。

原版下载到 PD 后可在 Windows 中运行作对照，Mac 负责分析副本和开发 Godot。原版 Mac 兼容移植按需另做，不作为 Godot 重制的必经步骤。

本轮未安装 Godot、未导入 Steam 原版、未建立 `project.godot`、未制作可运行游戏或发布包。现有正式 MOD 游戏与真实存档未改动。
