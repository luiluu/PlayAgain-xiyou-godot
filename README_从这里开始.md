## 保存资料的规则

1. 原版保留在 PD Windows，通过只读桥接访问；若另取快照，再放 `01_再刷一把/01_待接收原版/`，核对后登记为基准。
2. 西游 MOD 的新资料继续存入原资料库；本分类引用唯一原件。
3. Godot 重制新增设计、工程和素材放入 `03_再刷重制_Godot/` 的对应目录。
4. 每项现行计划、状态、来源与规范只有一份原件，通过链接引用。历史副本仅留在备份中。
5. 每轮收工运行 `03_再刷重制_Godot/07_开发环境/检查.sh`，更新交接板与变更记录后提交。

`02_再刷西游/现有资料库` 是目录链接。编辑其内容会修改旧资料库中的原件，不能把链接目标当作重复文件删除。

用户明确原版不做 Mac 移植。本期以最新正式 Mac 西游改版为来源，不需要先审计 Steam 原版；原版调用能力保留，未来用途按需决定。

当前进度见[交接板](./00_项目管理/交接板.md)与[重制步骤清单](./00_项目管理/重制步骤清单.md)。现有正式 MOD 游戏与真实存档不在重制任务中改动。
