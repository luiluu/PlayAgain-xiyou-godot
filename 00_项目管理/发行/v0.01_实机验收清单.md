# v0.01 整包实机验收清单（Mac、Windows、安卓）

日期：2026-11-11　作者：cc（Pro）　读者：Kyo　状态：草稿，未经审查

这次整包是给玩家的第一个包（v0.01）。它带新的启动动画、声明屏、新标题和「检查更新」，大厅漩涡进入二阶段、苍龙破晓解放、大厅有初步异化；**天启篇的内容不开放**，新游戏走原版开局。这份清单只查这些。

平台各自的细项（SmartScreen、高 DPI、手柄、输入法、签名公证、挂机通知、导入导出等）还在原来三份清单里：[Mac 发行包](../Mac发行包验收清单.md)、[Windows 发行包](../Windows发行包验收清单.md)、[安卓发行包](../安卓发行包验收清单.md)。这次不用重走，有空再补。

## 怎么走（共约 30 分钟）

| 顺序 | 平台 | 走哪几节 | 预计 |
| --- | --- | --- | --- |
| 1 | Mac | 全部（第 0～9 节） | 16 分钟 |
| 2 | Windows | 第 0、1、2、7 节，第 5 节只做 5.1～5.3 | 7 分钟 |
| 3 | 安卓 | 第 0、1、2、7 节，第 5 节只做 5.1、5.3，再做第 8 节 | 7 分钟 |

- 大厅（第 3、4 节）、天启篇和异化拿不到（第 6 节）、战斗（第 9 节）是跨平台一样的逻辑，Mac 上过了就算过。别的平台上碰巧看到不对，也照样记下来。
- 每条做完打勾。不过就记：**平台、第几条、做了什么、看到什么**，截图或录屏更好。不用判断原因。
- 标「⏳」的条目依赖还没合进 main 的功能（见文末「这份清单依赖什么」）。拿到的包里没有这些功能，就写「包里没有」后跳过，不算不过。

## 0. 开始前（每个平台 1 分钟）

- [ ] 0.1 **备份存档目录**，整个复制到别处（目录还不存在就跳过）：Mac `~/Library/Application Support/KYO/再刷重制/`；Windows `%APPDATA%\KYO\再刷重制\`；安卓不用备份，验完卸载即可。
  - 预期：复制后文件数一样。
- [ ] 0.2 **全新开始**：这次要看「第一次打开」的样子，所以备份后把这个目录清空（安卓是新装，或者在系统设置里清除本应用的数据）。
  - 预期：后面第 1 节看到的是第一次启动的流程。
- [ ] 0.3 **原版不受影响**：原版游戏和它的存档这次都不动。
  - 预期：验完后原版存档的修改时间不变。

## 1. 启动动画和声明屏（2 分钟）

- [ ] 1.1 打开游戏，什么都别按。
  - 预期：先放一段 4～5 秒的启动动画，合眼后压黑；接着出黑底红条的「警告」声明屏（本游戏免费、禁止倒卖），停留约 5 秒后自己淡出；标题从黑里慢慢亮起，眼睛睁开、Logo 上浮，菜单最后淡入。全程无卡顿、无爆音，动画不闪也不拉伸变形。
- [ ] 1.2 退出再开，动画一开始就按一下确定键（安卓点一下屏幕）。
  - 预期：动画立刻压黑，跳到声明屏，**不会**连声明屏一起跳过。
- [ ] 1.3 声明屏刚出现就连按确定键。
  - 预期：前半秒左右按了没反应（防连按），之后再按一下就淡出进标题。
- [ ] 1.4 标题进场途中（眼睛还在睁）按一下确定键。
  - 预期：直接跳到最终画面，菜单可用，不会顺手触发「新的游戏」。
- [ ] 1.5 看标题本身。
  - 预期：五项菜单「新的游戏、旧的回忆、游戏设置、游戏成就、检查更新」；上下移动有光标音，选中项放大、光标滑过去；右下角有版本号，写的是这次的版本；**没有**「返回版本选择」和「新版」入口。
- [ ] 1.6 进游戏后再回到标题（第 5 节会做到，届时顺便看）。
  - 预期：不再放启动动画和声明屏，直接是标题最终画面。

## 2. 检查更新（2 分钟）

v0.01 是第一个整包，网上还没有比它新的版本。

- [ ] 2.1 联网状态下，标题上选「检查更新」。
  - 预期：弹出一页，先显示「正在检查」，几秒内变成「已是最新」；版本号与标题右下角一致；按确定、取消或点页面外的暗处都能关，关掉回到标题。
- [ ] 2.2 标题上的「检查更新」旁边。
  - 预期：没有红点（没有新版本时不该有）。
- [ ] 2.3 断网（Mac／Windows 关 Wi-Fi，安卓开飞行模式），再点一次「检查更新」。
  - 预期：显示读不到、提示稍后再试或去 QQ 群；不闪退、不卡住，能关回标题。恢复网络后再点，回到「已是最新」。
- [ ] 2.4 全程留意。
  - 预期：不会自己打开浏览器，不会自己下载任何东西。

## 3. 大厅：漩涡二阶段和苍龙破晓 ⏳（Mac，4 分钟）

接第 5 节的新游戏走到方桌大厅后做。第一次进大厅照原版先播一段漩涡过场，这是一阶段的，正常。

- [ ] 3.1 第一次进大厅的过场播完后，看大厅正中的漩涡。
  - 预期：漩涡比原版大（约两格宽），转得比原版快；它占的格子和左右两边走不过去，其它地方照常走。
- [ ] 3.2 走到漩涡跟前调查。
  - 预期：照旧被弹回两格，文字换成了新的一句；不会进到漩涡里，不会卡在墙里。
- [ ] 3.3 离开大厅（进任意一层再回来，或存档、回标题、读档）。
  - 预期：第二次进大厅时自动播一段新的漩涡过场：画面变暗、有字幕、漩涡闪光震屏，苍龙破晓被甩出来，之后淡出。过场中按键不会乱跳，结束后能正常走动。
- [ ] 3.4 再离开、再回大厅一次。
  - 预期：这段新过场不再播。
- [ ] 3.5 回标题，新开一个档（或读另一个档）进大厅。
  - 预期：新过场也不再播（全存档只播一次）。
- [ ] 3.6 去兑换大厅的号角商店看。
  - 预期：能看到苍龙破晓的号角。按原版超强者的规矩，低难度不开挑战时买不了或用不了，会有提示。条件满足时（高难度存档，或开挑战）用号角，苍龙破晓入队，并带上他的专属法宝。
- [ ] 3.7 苍龙破晓入队后，在菜单里看他的技能和法宝说明。
  - 预期：说明里没有乱码、没有显示成变量号的数字；法宝写的专属角色是他本人。
- [ ] 3.8 （有高等级存档才做）带他打一场普通战斗。
  - 预期：他学到的主动技能能放出来、打得出伤害，不是只会普攻。具体伤害高低不用判断。

## 4. 大厅：初步异化 ⏳（Mac，2 分钟）

- [ ] 4.1 站在大厅北边 NPC 那一排看漩涡周围。
  - 预期：只有漩涡周围一圈不对劲（地面有裂纹、颜色发暗、有几块地砖微微浮起、有细小光尘往漩涡飘），圈外的地面、墙、NPC 和原来一模一样。
- [ ] 4.2 在圈里来回走，踩过浮起的地砖。
  - 预期：哪里都能走，通行和原来一样；浮砖踩上去被压平，离开后慢慢浮回。
- [ ] 4.3 走近漩涡、再走远。
  - 预期：能听到低沉的嗡声，越近越响，最响也不压过背景音乐；走出大厅就停。背景音乐本身没变。
- [ ] 4.4 和大厅里的几位 NPC 说话（讨债人三人、大工匠、动保协会成员、猫）。
  - 预期：原来的对话和功能照旧；原对话说完后，有的人多一句话，同一个档再找他不会再说。
- [ ] 4.5 在设置里关掉画面特效（有这个开关的话）。
  - 预期：光尘、氛围小字消失，其它照常。
- [ ] 4.6 全程留意。
  - 预期：不会突然弹窗、不会锁操作、不会进战斗、不会给东西或扣东西。

## 5. 新游戏流程和存读档（Mac 4 分钟，其他平台 2 分钟）

**5.1 新游戏**

- [ ] 5.1.1 标题选「新的游戏」。
  - 预期：走的是原版开局（原版的存档位、难度、名字、规则说明，选英雄，选教派），**不是**天启篇的新开局页面；最后进方桌大厅。不闪退。
- [ ] 5.1.2 开局中翻对话、选选项，用确定、取消各试几次（键盘、鼠标；安卓用触屏和返回键）。
  - 预期：对话正常翻页，选项光标正常，选中的那项生效；任何一步都不会卡死。
- [ ] 5.1.3 第一次到大厅。
  - 预期：照原版自动存档并提示；第一次进大厅的过场照原版播。

**5.2 存档（Mac、Windows）**

- [ ] 5.2.1 大厅里走几步，主菜单存到 1 号位，再按 `~` 一键存档。
  - 预期：都提示存档成功；存档目录里有刚存的文件，修改时间是刚才；**没有**出现 `再刷重制_开发` 目录。
- [ ] 5.2.2 进第一层，走几步，存到 2 号位。
  - 预期：1 号位和 2 号位都在，互不覆盖。

**5.3 回标题和读档（全平台）**

- [ ] 5.3.1 主菜单「游戏结束 → 回到标题」。
  - 预期：回到标题，直接是最终画面（不重放动画和声明屏）。
- [ ] 5.3.2 「旧的回忆」读 1 号位，再回标题读 2 号位。
  - 预期：位置、金币、队伍和存档时一样；读档不闪退；读档页按取消能回标题。
- [ ] 5.3.3 退出游戏再开，读 2 号位。
  - 预期：和退出前一样；这次启动照常放动画和声明屏（每次启动放一次）。

## 6. 确认天启篇内容和异化装备拿不到（Mac，2 分钟）

这一节查「不该有的东西没有」。用第 5 节新开的档看。

- [ ] 6.1 新游戏开局。
  - 预期：没有天启篇专属的开局页面（选档、选难度、随机阵容那一套），走原版开局（同 5.1.1）。
- [ ] 6.2 大厅。
  - 预期：没有天启篇的引路人问道号；招募照原版（号角、事件照旧能拿人）；没有通关抽角色。
- [ ] 6.3 主菜单 → 装备。
  - 预期：装备栏位和原版一样，没有天启篇新加的栏位；装备说明里没有天启篇的新词条。
- [ ] 6.4 商店（大厅和第一层能逛到的）。
  - 预期：没有天启篇的装备、异化装备或新道具上架。
- [ ] 6.5 打两三场战斗，看掉落和指令。
  - 预期：掉落里没有天启篇的装备或异化装备；战斗指令里没有天启篇加的「换人」。
- [ ] 6.6 读一个原版开局建的旧档（第 5 节存的就行）。
  - 预期：一切照原版，没有被套上天启篇规则。
- 补充：原版自带的「深渊异化」（敌人名字前带【异化】、主菜单的异化工坊）现在按 O-283 保持开启，不在这一节的「拿不到」范围里。要它也关掉的话告诉我。

## 7. 常见战斗（Mac 3 分钟，其他平台 1 分钟）

- [ ] 7.1 打一场普通战斗：普攻、技能、物品各用一次。
  - 预期：选指令、选目标正常（安卓点按也行）；伤害数字、动画、音效对得上；胜利画面背景清晰，结算后回地图。
- [ ] 7.2 （Mac）打一场时打开自动战斗和变速。
  - 预期：自动出招，速度变快；关掉后恢复手动和原速。
- [ ] 7.3 （Mac）试一次逃跑。
  - 预期：逃跑成功回地图，地图音乐接回来；失败的话照常挨打，不卡住。
- [ ] 7.4 （Mac）打到一次升级。
  - 预期：升级提示和音效正常。
- [ ] 7.5 （Mac，方便就做）全灭一次。
  - 预期：照原版回标题，读档能接着玩；不闪退。

## 8. 安卓补充（2 分钟）

- [ ] 8.1 新游戏开局里，每一步按一次系统返回键（或手势返回）。
  - 预期：等同于取消；不会直接退出游戏，不会卡在某一页。
- [ ] 8.2 回到标题后按一次返回键。
  - 预期：提示「再按一次返回键退出」，两秒内再按一次退出；之后再打开正常。
- [ ] 8.3 地图上切到别的应用，半分钟后切回。
  - 预期：画面、声音正常，人物不会自己一直走。
- [ ] 8.4 刘海或挖孔那一侧。
  - 预期：标题菜单、版本号、屏幕按键都没有被挡住。

## 9. 退出（每个平台 30 秒）

- [ ] 9.1 正常退出（Mac ⌘Q；Windows 点 × 或 Alt+F4；安卓标题按两次返回）。
  - 预期：直接关掉，没有「意外退出」或「应用已停止运行」的提示。
- [ ] 9.2 验完想恢复原来的存档，把第 0.1 条备份的目录拷回去。

## 不过时怎么报

在项目里说一句：平台和机型、第几条、做了什么、看到了什么。闪退的话附日志：Mac 是 `~/Library/Logs/DiagnosticReports/` 里今天新出现的文件；Windows 是 `%APPDATA%\KYO\再刷重制\logs\` 里最新的 `godot*.log`；安卓连着 Mac 时我可以取 logcat，没连就先别清应用数据。
