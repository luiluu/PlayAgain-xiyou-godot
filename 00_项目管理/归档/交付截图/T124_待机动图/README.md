# T124 全角色待机观察页

先打开 [总览.gif](总览.gif)（400×550，约320KiB，方便手机转发）；打开 [index.html](index.html) 可看25组原生4倍单图，并查看单独的素材参考。

主总览按协调方修订口径：20组动画、5组定帧。25组沿用T123编号，08/20、09/21两对登记最终指向同一本体，保留编号以便对照；不代表25个独立角色。u1样稿已排除，25改取 gpt/yunshang-v2 的u2待合图。逐组判断为本轮观察意见，交叉核查待协调方安排，不作自动门禁；“乱动”描述视觉变化，武具设计动作是否保留由美术核查判断。

所有单组均最近邻4倍、统一深灰底、固定原始画布锚点，不做逐帧居中或脚底对齐。主总览为手机缩略图，各格等框适配，故不同原始画布在总览中的缩放不同；细看以单组4倍图为准。总览为2.4秒、约6.7Hz采样循环摘要，交界处重起，完整帧速看单组；整目录约5MB（含素材参考、检查拼图和4倍原图），≤400KB目标仅手机主总览满足。

这里还原的是普通健康状态下的身体取帧，未叠加运行时影子、呼吸缩放、浮动、状态特效和其他角色的绑定组合；不是实战录像。原始素材三帧另附 [素材参考.gif](素材参考.gif)，其中定帧角色的原始walk三帧不能作为实战待机证据。

## 代码依据

- A：`modes/xiyou/core/appearance.gd:335` 的 `_mv_sheet`：普通walk使用第0行，循环顺序0→1→2→1。
- B：同文件`:349` `_super_sv`、`:387` `_state_sv`：逐帧按源动作帧数顺序循环；帧速取角色元数据，状态SVspeed不生效。饿狼角色SVspeed=12（200ms），因此星空／人类也用200ms；宿傩完全体状态虽写10，角色无覆盖，仍默认6（100ms）。
- C：`modes/xiyou/battle/battler_sprite.gd:290` `motion_tick`、`:646` `_guyu_planted`：谷雨、璇、屠苏本体静止时walk转wait且锁第0帧；`modes/xiyou/core/xuan_tusu_art.gd:128` `meta`：璇／屠苏本体wait一帧，绑定武具三帧，SVspeed=14（233.3ms，GIF取230ms）。
- D：`appearance.gd:170` `form_meta`：米拉黑龙walk实际4帧，SVspeed=10（166.7ms，GIF取170ms），故主图保留第4帧，参考页仅取原前三帧。
- E：`gpt/yunshang-v2` 的 `yunshang.gd:6` `art_path` 映射u2；该分支 `appearance.gd:115` 去掉旧逐帧标签，走u2图第一行0→1→2→1；旧版11仍走`sv/yunshang`三帧、200ms。u2并未合入当前基底，明确标待合。
- 普通动作默认 `battler_sprite.gd:9` MOTION_SPEED=6，每60Hz逻辑帧累加，故100ms。源元数据取共享generated/db/Actors.json和States.json，只读。共享generated图片只读回退；content优先当前工作树。`manifest.json`逐组记录源路径、SHA256、帧序、时长；`generate.py`可复现产物（Pillow环境，本次使用`/tmp/ring-art-venv/bin/python`）。
