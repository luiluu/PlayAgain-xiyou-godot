## 范围与设计

13项：千早爱音、五河琴里、黄泉、伏黑甚尔、宿傩人形、饿狼基础、饿狼人类、谷雨、屠苏本体、屠苏弓、璇、哈基米、五条悟。协调已明确：饿狼星空与宿傩完全体归 T151，屠苏书/锤/盾/剑归 T114。原图、ActorNote 摘录分别见 sources/ 与 actor_notes.json，不凭文件名推断体型。

每项重新编排整段三帧待机，使用一致中性姿态的头颈呼吸层，0→1→2→1循环：头部只在中相向下1原生像素，手与支撑区保持；弓固定侧立朝向、握持点与轮廓，以弦光变化替代人形呼吸。猫保留剑侧区域，猫头作1像素呼吸；尾巴、持剑爪和后足保持。谷雨、屠苏、璇、哈基米保持原形象识别特征，未做 T114 的形象改版。

动作整套选择狗逍遥待机为设计参照，里德用于复核。`*_reference.gif` 从左至右为狗逍遥、里德、新稿，按原生像素同倍率、底边对齐展示，不自动居中消除漂移。参照图与哈希已随目录保留。它们是离线审样动画，未模拟实际游戏速度。

黄泉、伏黑甚尔因 T136 已确认行走身轴滑动，重画四向各三帧。原生整理固定头区中轴，保留手臂与腿部步态，第三相换为相反支撑；甚尔右向由左向镜像形成，防止朝向跳变。其余11项本轮不改行走。尚须美术复核步态自然度与接触期支点，不以三帧不同自动证明步态合格。

## 规格与证据

- 39张独立待机帧、13张三帧条；黄泉与甚尔另24张48×48行走帧和2张144×192行走图集。
- 待机保留原规格：64×64，饿狼基础192×176，谷雨160×160，屠苏/弓/璇128×128，哈基米192×160。可见尺寸与格内放置依原首帧；这是修动作，不统一形象比例。
- native_report.json 记录原格尺寸、原轮廓框、头层截止线。verify.py 只读核对透明二值alpha、63帧尺寸、循环首尾、头层1像素移位、支撑区逐像素一致、行走三相独立及图集边缘留空；verification.json 含结果与PNG哈希。此为分层区域验证，未冒充人工人体关节点数字门禁。
- 内置 image_gen 每角色独立出候选，无付费 API；raw/ 保留生成原稿，sources/ 保留原图及两套待机参照，source_hashes.json 可核来源。生成时明确保留原形象；最终形象是否足够忠实以原版并排审样为准。
- Swift 后处理做最近邻原生栅格整理、透明化、固定姿态层、呼吸与步态相位编排；没有覆盖游戏 content。完整过程为 build.swift → original_walk.swift → walk_rig.swift → overview.swift → reference.swift；从仓库根运行，各脚本参数均为本目录路径，建议先 swiftc -O 编译，避免解释模式逐像素读取较慢。
- 只绘本卡待机及两角色行走，其余战斗动作和动作回退表未改变。未启动 Godot，未做18动作或实机播放验收；未修改复用待机帧的其他动作。
