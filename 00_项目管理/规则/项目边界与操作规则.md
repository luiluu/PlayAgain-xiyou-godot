## 操作规则

- 只读正式西游应用与 PD 原版；不在它们、已核对基准或旧 MOD 上实现 Godot 改动。不读写真实玩家存档。
- MV 参照引擎 `03_转换工具/mv_oracle` 写入只限其 `.sandbox/`，不要去掉文件系统守卫。
- 不移动或关闭正式游戏、虚拟机或对方仍在验收的进程。
- Git 管理文档、工具与工程；下载原件、外部资料库链接、备份、导出包、再生成缓存（含 `node_modules`、`.godot`）与密钥不入 Git。
- 模式、角色、技能、效果、来源映射使用稳定 ID。两模式不自动共用角色库、装备、进度或存档。
- 普通角色通过模板与效果参数接入，新机制放独立效果模块；改共用机制要验证已有角色的行为，战斗规则用 `mv_oracle` 对照正式版。
- 转换工具记录输入 SHA、输出清单与无法处理项。
- Godot 版本与导出模板版本匹配，以环境登记为准；使用官方签名应用，编辑器配置留在本库 `editor_data`。
- **当前只做 Mac 版**（用户 2026-10-12）：先完成 Mac 版重制；Windows、Android 暂不开发、不导出、不做手机/触控专项适配，Mac 版完成后再启动。代码不刻意写成 Mac 专用。各平台实际测试分别记录；打包成功不等于实机通过。
- 公开发行编号尚未分配，发布前另定；不复用旧 MOD 的内容编号（v0.04）。
- Godot 测试放 `01_Godot工程/tests/*.tscn`，输出一行 `TEST_RESULT={json}`，失败时以非 0 退出；`检查.sh` 会自动运行全部测试。偶发失败一律修稳，不靠重跑过关；测试里播过音效的，退出前停掉播放器后按真实时间等 0.5 秒（`create_timer(0.5, true, false, true)`）再退出，否则满负载下会报「resources still in use at exit」（用户 2026-10-17）。
- **可优化处先优化并登记**（用户 2026-10-13；2026-10-15 重申：原版有问题或不合理的内容，按自己的思路先改，记录下来用户最后确认）：重制中能改进的地方，执行者可先按自己的设计优化，但每处都登记在 `03_再刷重制_Godot/00_设计/优化登记.md`（原版行为、优化、理由、恢复方法），做成可回退；用户在重制完成后逐条决定去留。用户已拍板的事项不在此列。
- 对玩家的发行说明简述更新方向；游戏内帮助准确说明效果和必要条件。内部完整机制与验收记录保留在本库。
