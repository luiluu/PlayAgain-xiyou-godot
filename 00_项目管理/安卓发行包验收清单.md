# 安卓发行包验收清单（再刷一把：天启篇）草稿

日期：2026-11-07　作者：cc（平台 FB）　读者：Kyo　状态：草稿，未经审查

给安卓包用。11-06 平台 DP 交付单里那份 8 步「真机测试清单」合并时随交付单删了，这里重写并补全。结构照 [Mac 发行包验收清单](Mac发行包验收清单.md)。

**先说包**：「安卓 发行」的正式签名证书（keystore）还是空的，要 Kyo 自己的证书才能出能发布的包。现在给你装的会是**调试签名**的包（只给试装，不发布）。包名 `local.kyo.remake`，和原版 `com.kyo.zaishuayiba157` 不同，装上不会覆盖原版、不碰原版存档。验收包（带验收页）包名是 `local.kyo.remake.verification`，和发行包能同时装。

## 开始前

- [ ] 1. **记机型**：手机型号、安卓版本（设置 → 关于手机）、屏幕比例（如 20:9）。后面每条不过都要附这个。
- [ ] 2. **装包**：把 apk 拷到手机上点开安装，按提示允许「安装未知应用」。期望：装好，桌面图标是天穹巨眼，名字「再刷一把：天启篇」。
- [ ] 3. （可选，出问题时我能取日志）开「开发者选项 → USB 调试」，用数据线连 Mac。不开也能做下面各步。

## 打开与标题

- [ ] 4. 点图标打开。期望：横屏，直接进西游标题，右下角显示版本号；刘海或挖孔那一侧没有按钮被挡住。
- [ ] 5. **闪退复测（11-06 那条）**：标题上点「新的游戏」。期望：进开局地图，不闪退。
- [ ] 6. 屏幕两边有黑边（19.5:9 一类长屏）是现在的设计（画面按 16:9 不拉伸），记一句看着能不能接受就行。

## 触屏操作

- [ ] 7. **摇杆**：左下摇杆往各方向推，人物走路；推到底再按住右下「跑步」，走得更快。期望：方向对、松手就停。
- [ ] 8. **确定／取消**：右下「确定」翻对话、「取消」开关菜单，各按几次。期望：每按一次只动一下；按住会连发。
- [ ] 9. **点按**：直接点地面走过去；菜单里点选项、上下拖动列表。期望：点哪走哪，列表能滑，滑动不会误点进去。
- [ ] 10. **两指点按**：两根手指同时点一下屏幕。期望：等于「取消」（开关菜单），不会让人物走路。
- [ ] 11. **隐藏按键**：右上「隐藏」按一次，屏幕按键消失；再按显示。退出游戏再开，状态还在。
- [ ] 12. **手机按键设置**：主菜单 → 选项 → 最下面「手机按键设置」：调轮盘大小、右侧按键大小、透明度，试「调整UI位置」拖动按键，再「恢复默认」。退出再进，设置还在。期望：按键不会被拖出屏幕，也不会进刘海里。
- [ ] 13. **存档键**：地图和主菜单里右上有存档键，按一次存档成功；进商店页时右上**没有**存档键。

## 返回键与切后台

- [ ] 14. **返回键**（或手势返回）：地图上按一次＝取消（开关菜单）。回到标题后按一次，出提示「再按一次返回键退出」，两秒内再按一次退出游戏。
- [ ] 15. **切后台**：游戏中（不是挂机）切到别的应用，半分钟后切回来。期望：画面、声音都正常，触屏键没有卡住（人物不会自己一直走）。
- [ ] 16. **切后台自动存档**：在地图上走几步但**不存档**，切到后台，然后从最近任务里把游戏划掉（杀掉）。再打开。期望：标题有「继续」，点它回到刚才的位置；手动存档位里的档没有被改。
- [ ] 17. **后台挂机补跑**：开挂机，切后台一分钟以上再回来。期望：屏幕中间显示补跑剩余时间，补跑期间游戏快进；点屏幕能停；补跑结束恢复正常速度。
- [ ] 17a. **后台挂机通知**（前台服务，android-bgidle1）：第一次开挂机时系统问能不能发通知，选允许。挂机中切后台。期望：通知栏有「再刷一把… · 挂机中」，计时在走，带「停止挂机」按钮；回到游戏通知自动消失。
- [ ] 17b. **长时间离开**：挂机中切后台、锁屏放 10 分钟以上再回来。期望：游戏没有被系统杀掉（不是从标题重开），补跑时长约等于离开的真实时间（锁屏那段也算），最多 4 小时。
- [ ] 17c. **通知上停止**：挂机中切后台，过一两分钟在通知上点「停止挂机」，再过几分钟回到游戏。期望：通知消失；只补到点停止那一刻；补完挂机结束（人物不再自动战斗）。
- [ ] 17d. **不给通知权限**：系统设置里关掉本游戏通知，再挂机切后台。期望：看不到通知，但回来照样按离开时间补跑，不闪退。

## 存档导入导出

- [ ] 18. **导出存档**：标题「导出存档」→ 选一个档位 → 系统文件选择器里选个文件夹（如「下载」）保存。期望：不弹存储权限申请；文件夹里多一个存档文件。
- [ ] 19. **导入存档**：标题「导入存档」→ 选刚才那个文件 → 选一个**空**档位。期望：读这个档能进游戏。再导入到一个已有档的档位：期望先提示，原来的档会先备份。
- [ ] 20. 拿一个别的文件（如一张图片）去导入。期望：提示格式不对，什么都不改。

## 游戏流程、性能、声音

- [ ] 21. 走一层楼、打三场战斗（含一场 Boss 若方便）、开关菜单几次。期望：没有明显卡顿；记一句流畅不流畅。手机明显发烫也记一句。
- [ ] 22. 战斗里点按选技能、选目标都能用；胜利画面背景清晰。
- [ ] 23. **声音**：BGM、音效都有；锁屏再解锁、来电或闹钟打断后回来，声音恢复。
- [ ] 24. 手柄（有蓝牙手柄就测）：十字键走路、A 确认、B 取消。期望：能用；接上手柄时屏幕按键怎么显示，记一句就行。

## 退出与收尾

- [ ] 25. 标题按两次返回键退出；或从最近任务划掉。期望：没有「应用已停止运行」提示。
- [ ] 26. 闪退了：记是哪一步、按了什么。连着 Mac 时我可以用 `adb logcat` 取日志；没连的话，再打开游戏前别清数据。
- [ ] 27. 验完想卸载：长按图标 → 卸载。存档会一起删，要留就先做第 18 步导出。

## 自动部分（不用你做，供对照）

- 云端「导出冒烟」：导出「安卓 验收」包，`apksigner verify`、`aapt2` 查包名、arm64-v8a、横屏、版本号、图标；把包里的资源打成 pck，用 Linux 模板跑 `xiyou_mac_export`、`xiyou_flow`。
- 本机 `发行入口冒烟.py --platform android --keys`：静态查发行包，再用 macOS 发行模板当替身载入资源跑入口和按键；有模拟器在跑才会真装上启动。
- 测试 `xiyou_platform`：桌面上把自己当成手机，测虚拟按键、返回键、安全区、导入导出、切后台。
- **真安卓系统**（平台 FB 二批，11-07 起）：云端 x86_64 模拟器（安卓 14）装发行包：启动后活着、标题按两次返回键退出、回车开新游戏不闪退、切后台再回来是同一个进程、logcat 没有崩溃行；四组按键（空格／J／回车开新游戏、一串确认取消）都按完到地图（启动参数写进包副本，FB 三单）。云端包多开了 x86_64、用一次性调试签名，只给冒烟。第 7～13、18～24 步的手感、性能、声音、文件选择器仍然只能真机看；本机模拟器照旧不用（Kyo 11-07）。
