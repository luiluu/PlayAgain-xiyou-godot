- 净化之雷：真实冻结源 Game_Action.evalDamageFormula，敌人从当前敌群取得；固定资源上限与奇偶资源，覆盖角色／敌人施法、致死／不死。48 例修复前效果全部不符；修复后 97 项断言通过。模块只认 857／858／4013 且公式 SHA 为 19428a3b…，未知块仍报告未翻译，不冒充全量脚本支持。
- 确定性：旧测试在创建战斗画面后重新 seed，掩盖了呼吸相位的随机数消耗。本轮从 setup 前只设一次种子，以规则直接执行为基准，比较真实演出、图标开关、快速战斗、time_scale 30；两种种子共 8 组，逐击伤害／暴击、资源／状态、奖励及下一次随机值一致。楼层流程加逐场敌群／回合／结果统计。
- 音效：冻结 rpg_managеrs.js 的 AudioManager.playSe 每次新建 buffer；本轮加连续两次音效并播及动画移除后全部续播的运行测试。
- 同步保护：非零退出、退出 0 但含 SCRIPT ERROR、自己克隆自己、坏 JSON／非对象指纹回退有回归；48 项工具测试通过。
