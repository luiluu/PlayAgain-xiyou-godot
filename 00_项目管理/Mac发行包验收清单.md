# Mac 发行包验收清单（再刷一把：天启篇）

日期：2026-11-06　作者：cc（平台 DQ）　读者：Kyo

这份是给**正式发行包**（`~/Applications/再刷一把：天启篇.app` 那种，双击直接进西游标题）的。带验收页的调试包另见 [Mac 实机验收清单](Mac实机验收清单.md)（输入法、Intel 真机、听音那几节照旧有效）。

自动部分已经做过（每次导出后可重跑）：

```bash
python3 03_再刷重制_Godot/07_开发环境/发行入口冒烟.py --keys
```

它在发行包里无头按了空格／J／回车开新游戏，以及一串取消、确认键，查进程活着、没有新的崩溃报告；`--arch x86_64` 在 Rosetta 下跑 Intel 那一半（11-06 两种都 10/10）。下面是它替不了、要你本人看的。每步做完打勾；不对就记下第几步、看到了什么，截图更好。

## 开始前

- [ ] 1. **备份存档**：把 `~/Library/Application Support/KYO/再刷重制/` 整个复制到别处（发行包的存档目录；调试包用的是 `KYO/再刷重制_开发`，两边互不影响）。期望：复制后文件数一样。目录还不存在就跳过。
- [ ] 2. **版本号**：双击打开游戏，标题右下角的版本号和总装告诉你的这次导出一致（如 `dev.38x`）。期望：对得上；窗口标题是「再刷一把：天启篇」。

## 标题与新游戏

- [ ] 3. **闪退复测（11-06 那条）**：在标题上直接按**空格**选「新的游戏」。期望：进开局地图，不闪退。
- [ ] 4. 退出游戏再打开，这次按 **J**，再来一次按**回车**。期望：都进开局地图，不闪退。
- [ ] 5. 开局剧情里用空格、Z、J、回车翻对话，用 X、K、Esc 试取消。期望：对话正常翻页，没有卡住、没有闪退。
- [ ] 6. 有对话选项时用方向键（也试 WASD）选、确认键定。期望：光标移动正常，选到的那项生效。

## 地图、菜单、存档

- [ ] 7. 地图上走几步（方向键、WASD、鼠标点地面、按住左键拖着走都试一下），按住 Shift 跑步。期望：走路正常，跑步更快。
- [ ] 8. 按 Esc（或 X、鼠标右键）开主菜单，进物品、技能、装备各看一眼再退出。期望：开关菜单不会立刻又弹出来；退出后回到地图。
- [ ] 9. **存档**：主菜单里存到 1 号位。再按 `~`（数字 1 左边那个键）试一键存档。期望：都提示存档成功。
- [ ] 10. **存档位置**：在访达里打开 `~/Library/Application Support/KYO/再刷重制/`。期望：里面有刚存的存档文件，修改时间是刚才。
- [ ] 11. **回到标题**：主菜单 →「游戏结束」→「回到标题」。期望：回到西游标题，不闪退。
- [ ] 12. **读档**：标题选「旧的回忆」，读 1 号位。期望：位置、金币、队伍和存之前一样。读档那一下不闪退（11-06 修的另一条路就在这里）。

## 战斗、商店

- [ ] 13. **战斗**：打一场普通战斗，用普攻、技能、物品各一次，打完看胜利画面。期望：伤害数字、动画正常；胜利画面背景清晰（11-05 定的不模糊）；回到地图。
- [ ] 14. 战斗里试一次逃跑或全灭（哪个方便试哪个）。期望：逃跑回地图；全灭按原版处理，不闪退。
- [ ] 15. **商店**：找一家商店，买一件、卖一件。期望：金币增减对得上；Tab 能切装备属性显示；离开商店回地图。
- [ ] 16. 再存一次档到 2 号位，读回 1 号位再读回 2 号位。期望：两个位置互不覆盖。

## 窗口、全屏、声音

- [ ] 17. **全屏**：按 ⌘+回车进全屏，再按一次退出；用 F11 再来一遍。各来回三次。期望：每次都能退回窗口，窗口回到原来大小，画面不变形。
- [ ] 18. 全屏时用 ⌘+Tab 切到别的应用，再切回来。期望：画面和声音都正常，按键没有卡住（比如松手后人物还在走）。
- [ ] 19. 拖窗口边缘改大小。期望：画面按比例缩放，两边或上下留黑边，文字不发糊（Retina 屏下看血条、图标边缘）。
- [ ] 20. **音量**：主菜单 → 选项，把 BGM、SE 音量分别调到 0 和 100 再调回来。期望：声音跟着变；退出游戏再打开，设置还在。
- [ ] 21. 整个过程里留意 BGM：11-06 起 BGM 降到 96k，期望听不出明显变差（没有爆音、循环接口没有咔哒声）。

## 退出与收尾

- [ ] 22. **退出**：点窗口左上红点，或 ⌘Q。期望：直接关掉，没有卡死、没有「意外退出」的系统提示。
- [ ] 23. **崩溃报告**：打开「控制台」应用 → 左边「崩溃报告」，或在访达里看 `~/Library/Logs/DiagnosticReports/`。期望：没有今天新出现的「再刷一把：天启篇-…」文件。有的话把文件发我。
- [ ] 24. （有 Intel Mac 才做）把 .app 拷过去双击打开，走第 3、9、12、13 步。期望：能进标题、不闪退，帧率说个大概。没有 Intel 机就跳过，自动冒烟在 Rosetta 下已经跑过一遍，但那不算真机。
- [ ] 25. 验完后，想恢复原来的存档就把第 1 步备份的目录拷回去。

## 不过时怎么报

告诉我：第几步、按了什么、看到了什么、期望是什么；闪退的话把第 23 步那个崩溃报告文件发我。
