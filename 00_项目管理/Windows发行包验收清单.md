# Windows 发行包验收清单（再刷一把：天启篇）草稿

日期：2026-11-07　作者：cc（平台 FB）　读者：Kyo　状态：草稿，未经审查

给 **Windows 发行包**（`再刷一把_天启篇.exe` 加同名 `.pck`，双击直接进西游标题）用。结构照 [Mac 发行包验收清单](Mac发行包验收清单.md)，只把 Windows 不一样的地方写细。没有 Windows 机器时这份先放着，自动部分见最后一节。

## 开始前

- [ ] 1. **拿包**：总装给的 Windows 发行目录里，`再刷一把_天启篇.exe` 和 `再刷一把_天启篇.pck` 必须放在同一个文件夹（exe 只认旁边同名的 pck）。期望：两个文件都在。
- [ ] 2. **备份存档**：打开 `%APPDATA%\KYO\再刷重制\`（资源管理器地址栏粘这串回车），整个复制到别处。目录不存在就跳过。期望：复制后文件数一样。
- [ ] 3. **原版不受影响**：原版的存档在 `%LOCALAPPDATA%\再刷一把 1.57\save`，重制不读也不写那里（底线规则，不迁移 MV 旧存档）。期望：这一轮做完它的修改时间不变。

## 首次打开

- [ ] 4. **SmartScreen**：包没有签名，第一次双击会弹「Windows 已保护你的电脑」。点「更多信息 → 仍要运行」。期望：进西游标题。不过：截图提示框，记 Windows 版本（设置 → 系统 → 系统信息）。
- [ ] 5. **杀毒软件**：如果 Defender 或别的杀软把 exe 隔离了，记下杀软名字和报的病毒名，不用自己放行。
- [ ] 6. **版本号**：标题右下角的版本号和总装说的这次导出一致；右键 exe → 属性 → 详细信息，「产品名称」是「再刷一把：天启篇」，文件版本是 `0.<开发编号>.0.0`。期望：都对得上。

## 窗口、全屏、高 DPI

- [ ] 7. **窗口大小**：首次打开窗口占屏幕大约九成、居中、不超出任务栏。拖边缘改大小。期望：画面按比例缩放，留黑边，不变形。
- [ ] 8. **高 DPI**：设置 → 显示 →「缩放」分别用 100%、150%（笔记本常见 125%／150%）各开一次。期望：文字、血条、图标边缘锐利不发糊，窗口不会大到超出屏幕。
- [ ] 9. **全屏**：按 **Alt+回车** 进全屏，再按一次退出；用 **F11** 再来一遍，各来回三次。期望：每次都能退回窗口，窗口回原来大小。（Mac 上是 ⌘+回车，Windows 上是 Alt+回车。）
- [ ] 10. 全屏时 **Alt+Tab** 切到别的程序再切回来。期望：画面和声音正常，按键没有卡住（松手后人物还在走）。
- [ ] 11. 有两块屏幕的话，把窗口拖到另一块屏再全屏。期望：在当前那块屏上全屏。

## 输入

- [ ] 12. **闪退复测（11-06 那条）**：标题上直接按空格选「新的游戏」；退出再开分别按 J、回车各一次。期望：都进开局地图，不闪退。
- [ ] 13. **键盘**：方向键和 WASD 走路，Shift 跑步；空格／Z／J／回车确认，X／K／Esc 取消；`~` 一键存档。期望：都有反应。
- [ ] 14. **鼠标**：点地面走路、按住左键拖着走、右键取消、滚轮翻列表。期望：都正常。
- [ ] 15. **中文输入法**：遇到要输入文字的地方（取名等），用微软拼音或你常用的输入法打「中文测试」，选候选词确认。期望：候选框跟着输入框，字能打进去。不过：记输入法名称、截图。
- [ ] 16. **手柄**（有 Xbox 手柄或兼容手柄就测）：十字键和左摇杆走路，A 确认、B 取消、X 跑步、Y 菜单、LB／RB 翻页。中途拔掉再插上。期望：都能用，拔插后人物不会自己一直走。不过：记手柄型号、按的键、预期、实际。

## 游戏流程与存档

- [ ] 17. 照 Mac 发行包清单第 5～16 步走一遍：翻对话、选项、地图、主菜单、存档到 1 号位、回到标题、读档、战斗、逃跑或全灭、商店、2 号位存读。期望：同 Mac 清单。
- [ ] 18. **存档位置**：打开 `%APPDATA%\KYO\再刷重制\`。期望：里面有刚存的存档，修改时间是刚才；**没有**出现 `再刷重制_开发` 这个目录（那是调试包用的）。
- [ ] 19. **音量**：选项里 BGM、SE 调到 0 和 100 再调回来，退出再开设置还在。整个过程留意 BGM 有没有爆音、循环接口咔哒声。

## 退出与收尾

- [ ] 20. **退出**：点窗口右上角 ×，或 Alt+F4。期望：直接关掉，任务管理器里没有残留的「再刷一把_天启篇」进程。
- [ ] 21. **崩溃日志**：如果中途闪退，把 `%APPDATA%\KYO\再刷重制\logs\` 里最新的 `godot*.log` 发我；再打开「事件查看器 → Windows 日志 → 应用程序」，找时间对得上的「应用程序错误」，截图。
- [ ] 22. 想恢复原来的存档，就把第 2 步备份的目录拷回去。
