# Mac 实机验收清单

日期：2026-11-05　作者：cc（哪吒 mac1）　读者：Kyo

## 为什么要你本人来

自动测试已证明：音频有非静音输出，输入法能提交中文，包内字体、资源、存档能读写，流程能从入口打到存读档。

但这几件事只有真人真机能判：好不好听、Intel 机器上跑不跑得动、玩家双击能不能打开。签名公证还要你的 Apple 开发者账号，我们不碰你的钥匙串。

做法：先跑自动命令，再做下面只有你能做的项。做完一项打一个勾。

## 0. 先跑自动部分

```
python3 03_再刷重制_Godot/07_开发环境/导出冒烟.py --keep
```

- [ ] 跑完后，`03_再刷重制_Godot/04_验证/本地结果/导出冒烟/<时间>/报告.md` 里没有失败项。不过：把报告路径告诉我。
- [ ] 报告里写了留下的 `.app` 路径，记下来，下文叫「验收包」。

## 1. 开始前

- [ ] 用验收包（带 `tests/`，能开交互验收页）。想看玩家视角，再自己导出「macOS 发行」试一遍（它没有验收页）。
- [ ] 备份存档目录：`~/Library/Application Support/KYO/再刷重制_开发/`（工程设的自定义存档目录），整个复制到别处。看到：文件数一致。
- [ ] 不用真实玩家存档。二选一：新建一个 macOS 用户来测；或启动时加临时 HOME：`HOME=<临时目录> <验收包>/Contents/MacOS/再刷重制`。
- [ ] 测完删掉临时目录或测试用户。不过：记目录里多了或少了什么。

## 2. Apple Silicon 实机（M1 Pro）

- [ ] 首次打开：验收包是本机临时签名，会被 Gatekeeper 拦。右键 App → 打开；或 系统设置 → 隐私与安全性 → 仍要打开。看到：进入入口画面。不过：截图提示框，记 macOS 版本。
- [ ] 窗口：拖动、缩放，画面不变形。
- [ ] 全屏：进出三次，每次都能回来，标题栏恢复。不过：记是第几次、什么现象。
- [ ] 全屏时切走别的 App 再切回，画面和声音正常。
- [ ] Retina：看文字、血条、图标边缘，锐利不发糊。胜利画面背景也清晰。不过：截图标出哪块糊。
- [ ] 帧率：走一层、打三场战斗、开关菜单，没有明显卡顿。不过：记场景和卡多久。
- [ ] 键盘：方向、确认、取消、菜单键都有反应。
- [ ] 手柄（有就测）：方向、确认、取消可用。不过：记按键、预期、实际。
- [ ] 存读档：新游戏进第一层并存档，退出，再开读档。看到：位置、金币、队伍和存前一致。再存第二个位置，两个互不覆盖。
- [ ] 退出：窗口正常关闭，无卡死、无崩溃提示。

中文候选词输入（交互验收页）：

```
HOME=<临时目录> <验收包>/Contents/MacOS/再刷重制 -- --verify-export --interactive --out=<目录>
```

- [ ] 在输入框用你平时的拼音输入法打「中文测试」，选候选词确认。
- [ ] 点「播放菜单音效并记录音频」，听到声音。
- [ ] 点「记录结果并退出」。看到：`--out` 目录里有结果文件和截图，文字完整。不过：把目录发我，说明输入法名称。
- [ ] 可选：换另一种输入法（五笔、手写）再试一次。

## 3. Intel 实机

需要一台 Intel Mac，借用即可。

- [ ] 在自己的 Mac 上先确认包里有 Intel 部分：`lipo -archs <验收包>/Contents/MacOS/再刷重制`。看到：含 `x86_64`（11-05 冒烟报告记的是 `x86_64 arm64`，通用包）。不过：只有 `arm64`，告诉我。
- [ ] 把验收包拷到 Intel 机，按第 2 节首次打开的办法打开，能启动并进入入口。
- [ ] 帧率：走路和战斗流畅，凭感觉说比 M1 慢多少。
- [ ] 音频：有声音，不爆音。
- [ ] 字体：中文都显示，没有方块。
- [ ] 存档：存、退出、读走通一轮（用新用户或临时 HOME，别动借来机器上别人的数据）。
- 不过就记：机型、年份、macOS 版本、现象，拍照或截图。
- [ ] 没有 Intel 机时的粗检：`arch -x86_64 <验收包>/Contents/MacOS/再刷重制`，能启动进游戏。**这不能代替真机**，帧率和声音不作数。

## 4. 主观听音

系统音量固定在一个中间值（如 50%），整个过程不动。耳机一遍、外放一遍。

每个场景都听这几点：

- 音量忽大忽小吗？与别的场景比差太多吗？
- 有爆音、噼啪声吗？
- 循环回头时有停顿或咔哒声吗？
- 切换场景时，上一首自然淡出、下一首淡入吗？
- 音效与动作对得上吗？有延迟或漏播吗？

| 听哪个场景 | 重点 | 耳机 | 外放 |
| --- | --- | --- | --- |
| 标题画面 | 开场音量，有没有突然开始 | [ ] | [ ] |
| 大厅 | 循环一圈以上，听接缝 | [ ] | [ ] |
| 普通楼层（走几层，含洞穴类） | 环境声（水滴、流水、低鸣）与音乐叠加是否过响 | [ ] | [ ] |
| 普通战斗 | 战斗音乐切入，攻击与受击音效对得上 | [ ] | [ ] |
| Boss 战 | 音乐切换明显、气氛对，不压过音效 | [ ] | [ ] |
| 胜利音乐 | 战斗音乐淡出后干净，不叠音 | [ ] | [ ] |
| 升级 | 提示音清楚，不被别的声音盖掉 | [ ] | [ ] |
| 菜单 | 光标、确认、取消、无效操作的提示音各一遍 | [ ] | [ ] |
| 失败画面（可选） | 失败音乐收尾自然 | [ ] | [ ] |

不过就记：场景名、第几分几秒、现象（太响／爆音／断档）。能录音就录。

## 5. 签名与公证

这一节**由 Kyo 本人执行**。这些命令项目里的 Claude 不执行，也不碰你的钥匙串。现在导出预设是 ad-hoc 签名，没有公证。

- [ ] 1. 加入 Apple Developer Program。为什么：不加入拿不到 Developer ID 证书。
- [ ] 2. 钥匙串里有 `Developer ID Application: …` 证书。为什么：这是签名用的身份，缺它后面都做不了。
- [ ] 3. 用它签名。二选一：在导出预设里填 codesign identity；或导出后手签 `codesign --deep --force --options runtime --sign "Developer ID Application: …" <app>`。为什么：公证要求正式证书加 hardened runtime。
- [ ] 4. 存凭据：`xcrun notarytool store-credentials <名字>`，按提示填 Apple ID 和 App 专用密码（在 appleid.apple.com 生成，别用主密码）。为什么：之后提交不必每次输密码。
- [ ] 5. 提交：先把 App 打成 zip，再 `xcrun notarytool submit <zip> --keychain-profile <名字> --wait`。看到 `Accepted` 才算过。为什么：Apple 扫描通过才发公证凭证。
- [ ] 6. 钉凭证：`xcrun stapler staple <app>`。为什么：玩家离线也能打开。
- [ ] 7. 验证：`spctl -a -vv <app>`。看到：`accepted`，来源 `Notarized Developer ID`。
- [ ] 8. 把包拷到一台没装过它的 Mac 双击。看到：直接打开，没有「无法验证开发者」提示。

不过就记：哪一步、完整报错原文；公证被拒会给日志链接，一并记下。证书和密码不要发给我，也不要写进项目。
