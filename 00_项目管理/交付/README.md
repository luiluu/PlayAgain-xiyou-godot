# 交付单

多会话并行时，车道不改交接板、变更记录、进度账等共用文件，要写进去的内容写在这里，由总装合并时并入后删除。规则见 [AGENTS.md「多会话并行」](../../AGENTS.md)。

- 文件名：分支名把 `/` 换成 `_`，如 `claude_六层.md`。每个分支一个文件。
- `main` 上除本 README 外不应留有交付单；`检查.sh` 在主工作区会报出未并入的交付单。

## 模板

```markdown
# 交付：<分支名>

- 车道／执行者：A 内容·楼层／Claude
- 状态：进行中｜可合并

## 变更记录草稿

（照 AGENTS.md「变更记录格式」写正文条目，标题里的开发编号写 dev.待定）

## 交接板

- 下一步：要新增、改写或删掉的条目
- 用户试玩说明：本轮玩家能看到的变化
- 需要用户决定：（如有）

## 进度账

- 部分：完成度 旧% → 新%，依据一句话

## 本分支提交

- <提交号> 简述
```
