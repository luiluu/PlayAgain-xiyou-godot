## 动了的共用函数和开关

| 函数／开关 | 调用方 | 逐处结论 |
| --- | --- | --- |
| `XTouchControls.hit` | `git grep -n 'hit(' -- '*/core/touch_controls.gd'` | 调用方 2 处逐处结论：按下触点与同一触点模拟出的鼠标事件使用同一命中判断。画布重挂前释放已有按压，原触点松手不会继续触发。 |
| `XTouchControls._ready` | 按键子节点进树 | 原尺寸变更连接仍同步重排，再统一排队补一次重挂。焦点与恢复通知同帧去重。 |

| `XItemScene.bag_gear` | `git grep -nE '\bbag_gear\(' -- '*.gd'` | 只有装备候选传入加速参数。物品页、商店、两个仓库、新皮肤物品页和独立测试都沿用默认参数与原排序路径。 |
