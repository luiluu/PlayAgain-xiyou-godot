### 「引用」怎么判（依据：逐个看了 tests/ 下 33 个 `xiyou_floor*`、6 个 `xiyou_map*` 场景的脚本）

一个场景的引用图号＝场景文件＋它挂的 `res://tests/*.gd` 脚本里，下列写法认出的图号并集（`选测.py MAP_REF_PATTERNS`）：

| 写法 | 例 | 为什么 |
| --- | --- | --- |
| `MapNNN`（三位） | 文件头 `## Map040：EV2 ⇄ Map042` | 每个楼层测试文件头都按图列出流程，覆盖最全 |
| 大写 `…MAP… := N` 常量 | `const MAP := 33`、`FLOOR_MAP` | floor16／28／30／31 用常量定起点图 |
| `_start(N, …)` | `_start(10, 10, 10, 2)` | 起点图（reach068 的 Map010 只在代码里） |
| `_wait_map(N)` | `_wait_map(88)` | 传送目的图（reach069 的 88／89／91／112、reach187 的 219 只在代码里） |
| `map_id == N` | `_scene().map_id == 4` | 核对停留在哪张图（fortress029 的 Map004 只在代码里） |
| `_goto(从, x, y, 事件, 到, …)` | `_goto(31, 9, 9, 2, 18, …)` | guild197／198 的起止图 |

只靠注释会漏 5 个测试的代码图号（上表后四行例子），所以注释与代码写法一并认。

**照旧全选的**：`xiyou_floor_run*`（楼层表从内容数据推出，遍历全部楼层，新加的层自动进来）；`xiyou_map.tscn`（对照探针给的全部地图逐张核通行）。另外认不出任何图号的楼层场景也照旧选（宁多跑）；现有 39 个场景都认得出。

**已知边界**：测试经事件途经、却既不在注释也不在代码里写出图号的中间图，改它时不会选到该测试；现有测试每次换图都 `_wait_map` 核对，没发现这种写法。新写楼层测试时照文件头列图的惯例即可。
