## 给后续卡（J～Q 照这里用）

**数量选择 `XSkinStepper`**（Control，高 `H`＝44；钮 44×44，「最多」64×44；宽不够时数字区先缩、钮间空再缩，宽 ≥280 都摆得下）

- 属性：`value`、`min_value`、`max_value`、`focused`（键盘焦点在数量条上：整条原地高亮）、`enabled`（false 变暗、不响应）、`show_max`（要不要「最多」）、`sound`（true 时改值自己响光标音；页面自己管音就设 false）。
- 方法：`set_range(lo, hi, v)`（不发信号）、`set_value(v, emit := true)`、`step(d)`、`to_max()`、`to_min()`、`type_digit(d)`（0～9，<0 退格；超上限夹上限、空算下限）、`handle_input(event) -> bool`（只认 ←/→ ±1、↑/↓ ±10、E 最多、Q 回 1、数字键；**确定、取消不接**，页面定）、`open_editor()`／`close_editor()`／`editing()`（点数字弹数字键盘；不自动弹）、`button_rect(i)`、`number_rect()`。
- 信号：`value_changed(value)`（只在值真变了时发）、`touched`（钮或数字被点：页面据此把焦点挪到数量条，商店是「先按一次确定」）。
- 触屏按住连加：0.4 秒后每 0.08 秒一次（`HOLD_DELAY`／`HOLD_STEP`）。
- 用法：

  ```gdscript
  var st := XSkinStepper.new()
  card.add_child(st)            # 放在牌底：XSkinCard 自己的 _draw 会盖掉 draw 信号画的字，合计等字放在牌的子节点里画（见 XSkinShopPage.foot）
  st.position = Vector2(card.pad, y); st.size = Vector2(card.size.x - card.pad * 2, XSkinStepper.H)
  st.set_range(1, max_make, 1)
  st.value_changed.connect(func(v): number = v)
  # 焦点规则（T254 3.0）：列表态上下只换行、不改数量；确定 → st.focused = true；焦点在数量条时先 if st.handle_input(event): return
  # 再确定＝成交；取消＝st.focused = false、st.set_value(1, false)
  ```

  商店没用 `handle_input`（数量键照旧走 XShop 的数量窗代码，音也照旧），制作、赌场框没有旧数量窗代码可借的直接用它。

**统一确认弹窗 `XSkinConfirm`**（铺满父节点，压暗 66%，宽 480，标题 26 号、后果一句 17 号 TEXT_2）

- `XSkinConfirm.open(parent, d)` 建好并 setup；或自己 `new()`＋`add_child`＋`setup(d)`。`d`：`title`、`body`、`buttons`（字或 `{text, disabled}`，2～3 枚，约定最后一枚是「取消」）、`danger`（找不回来的操作：橙边、默认停最后一枚；否则灰边、停第一枚）、`index`（给了就用）、`width`。
- 信号：`chosen(i)`（确定或点当前钮；禁用的钮也发，页面自己蜂鸣）、`index_changed(i)`、`cancelled`（取消键）。方法：`handle_input(event) -> bool`（开着时吞掉键盘／手柄键；左右、上下换钮）、`select(i)`、`default_index()`、`is_disabled(i)`、`close()`。
- 本件不响音。点：点非当前钮＝选中，点当前钮＝确定；点弹窗外不算取消。
- 两种用法：一次性（`open`＋连 `chosen`／`cancelled`＋`close`）；页面有自己的状态（商店 `_confirm`）就每次重画 `setup(…＋index)`，在 `chosen`／`index_changed` 里写回。

**页内页签 `XSkinInnerTabs`**（高 32，17 号 TEXT_2，当前 TEXT_HI＋2px 旧金下划线，不用红）

- `set_tabs(arr, i)`、`select(i, emit := true)`、`handle_input(event) -> bool`（只认 Q／E，到头循环）、`tab_rect(i)`；信号 `changed(i)`；`sound` true 时自己响光标音。点字就换。
- 放在列表标题下面一行；商店的摆法见 `XSkinShopPage._place_tabs`（列表整体下移 36，行数按剩下的高重算）。

**面包屑 `XSkinCrumb`**（高 24，15 号 TEXT_2，「›」TEXT_3，最后一段 GOLD）：`set_parts(arr)`；或不建节点，`XSkinCrumb.draw_parts(ci, 基线位置, arr, max_w)`；放不下从前往后换「…」（`fit_parts`），最后一段永远完整。只显示，返回上一层由页面接取消键。

**小标、空列表 `XSkinTag`**（静态画法）：`draw(ci, Vector2(左, 竖直中线), 字, 颜色可省)` 返回宽；`width(字)`、`height()`（≥22，字号随字体设置）、`color_for(字)`（「新」「穿着」「出战…」「领队」旧金，其余 TEXT_2）、`row_width(tags)`、`draw_empty(ci, rect, 一句)`（19 号 TEXT_3 居中）。

**`XSkinList` 新行键**（不给就和以前逐像素一样）：

- `tags`：`["新", "已锁定"]` 或 `[{text, color}]`；画在名字后，名字放不下先缩名字、小标不缩；`sub` 接在小标后面。
- `check`：0 空框、1 金色 ✓；没这个键的行不画框。要整表先设 `list.check_column = true`（行首留 28）。点框的接法见 `XSkinShopPage._on_list_gui`（按下记行、松手同一个框才算，免得变成选中）。
- `list.empty_center = true`：空列表一句画在列表区正中（`empty_text`）。

**套页的做法**（`XSkinShopPage` 可当样板）：旧页状态机不动，`XUiSkin.on() and X.ENABLED` 时建新页；旧页 `_refresh` 末尾 `skin.sync()`（并跳过旧窗口重画），`_unhandled_input` 开头 `if skin.input(event): return`，`_gui_input` 有新页时直接 return；新页只把点击翻成旧页同样的状态变化。牌底要画字的放牌的子节点（`foot`）。

## 没做／偏离

- **换人键用 ←/→，不是稿里的 Q／E**：购买列表上 Q／E 是整页翻（稿「翻页」），出售列表上 Q／E 是换页签，再给「换上后」换人就撞键；旧页本来就是左右换队员，照旧。稿里样稿按键提示写的「Q/E 换人」不采用。
- 「换上后」每项只写增减（▲48），没写「89 → 137」：旧状态窗也只有增减；要算换上后的总值得模拟换装，不在本卡。Tab 看法（一项属性×全队）只有键盘能切，触屏没有入口（旧页是点状态窗上沿）。
- 环上三个球用的是占位图标（精魂、物品袋、武器图标号），不是样稿的单字「买」「卖」「批」：环组件现在只认图标；美术或卡 E（单字球）出了再换。只买不卖的店左块「主视觉」先放精魂图标＋「购买」二字。
- 一键出售列表照代码有九行（「保留词条」行、七档、「出售类别」行，O-606 加的），不是稿里的七行（稿跟代码对不上以代码为准）。全档都被自动留住时写「全留住」（稿没写这种情况）。
- 稿的动效（换分类内容 0.12 秒淡入上移、数值变了闪一下金色）没做：模板页本来没有，放进统一动效那张卡更合适。被选中的禁用行字提到 #c9cbd0 没做（列表组件现在禁用行一律 TEXT_3）。长名字：列表组件现有做法是先缩到 16 号再省略，不是稿里的「不缩字直接省略」，没改（会动到所有页）。
- 数量条的按住连加、点数字弹键盘没有自动测（要真触屏）；自动测了点钮、点主按钮。
- 皮肤关闭对照：脚本本身起 Godot 不带 `--audio-driver Dummy`，我照它的步骤在 scratchpad 里拷了一份加上该参数跑（结果同上）；脚本本身没改。
- 截图是窗口直接设成 800×450／1000×450 拍的（不是大图缩小）。
