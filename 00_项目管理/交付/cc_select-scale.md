# 交付：cc/select-scale

- 车道／工作者：B 界面「T024 全局选中放大」（cc 车道，Orca task_20b29b89e644，Opus＋medium：改新皮肤公共选中表现、覆盖全部页面）
- 状态：可合并

依据：Kyo 11-16「选中的东西都要稍微放大，不只装备页，其他所有选中都做」；底子是 T002 新皮肤 v7（dev.634）装备栏位环的选中放大（`XUiSkin.SEL_SCALE` 1.15、`SEL_TIME` 0.12 秒）。

## 结论

- 新增一处公共实现 `XSkinSelScale`（`modes/xiyou/ui/skin/skin_sel_scale.gd`）：控件 `attach(self)` 挂一个内部小节点，画的时候 `sel(当前键)`、取 `k(键)`；新选中项 0.12 秒从 1 长到位、离开的缩回 1，**界面动效关时直接到位**，页面刚打开时已选中的那项直接是放大的；只在过渡中每帧重画宿主。总开关 `XSkinSelScale.ENABLED`（关＝全不放大，战斗指令球回到原来直接 ×1.08）。
- 各控件只放大**内容**（图标、名字、头像），**行高、选中条、按钮框不变**，名字仍按本行余宽先缩字再省略，所以不碰邻行、不压右列、不出界；字号再按行高封顶（列表 0.6×行高，46 行→27 号），130% 字号不顶行边。
- 皮肤关着时这些控件根本不建；旧 MV 画布的钩子另判 `XUiSkin.on()`，皮肤关对照一行不变（专项 `mv_skin_off_no_scale`，`xiyou_ui_skin_close` 等选测全过）。

## 不放大的（想过、有意不做）

- 战斗右上队伍条（`skin_side_status`）轮到谁的那行、行动顺序条、首领状态胶囊、目标锁定提示：是「状态显示」不是玩家移动的选中，而且战斗里跟着演出变；目标提示自己已有 0.2 秒从大缩到位的锁定环。
- 红乙选中条本身（`XSkinSelectBar`）：条放大就会压邻行，只放大条上的内容。
- 七印祭坛的印：本来就「选中的那枚放大」，不重复加。
- 工坊顶上页签（`focus_mode = NONE` 的按钮，用 Q/E 换页、不拿焦点）：当前页签没放大，见「我不同意的地方」2。

## 我不同意的地方

1. **验收写「1.05～1.15」，我按挤不挤分了三档**：一般控件 1.15（和装备页 v7 一致）；战斗指令球 1.08（1.15 会和邻球相叠 2px，专项 `battle_ring_apart_2..16` 按 1.08 断言 2～16 项都不相叠）；旧 MV 页行和新皮肤按钮 1.05～1.08（MV 行 36 高、字 28 号，按钮是整块缩放，再大就压邻钮）。要统一成一个数的话改 `XSkinSelScale.peak` 默认值和这两个常量即可。
2. **旧 MV 页用的是画布级的通用钩子**：只放大「光标之后画的」字和图标；个别页面先画字后画光标、或绕开 `XMVCanvas.text/icon` 直接画的，那几处不会放大（不会画错，只是没效果）。等这些页换成模板页（第 5 期）自然就有。工坊顶上页签同理（Button 但不拿焦点），没为它单开一套。
