## 给后续卡（天衣铺、屠苏器谱、星谱，或别的串联菜单照这里用）

**层级菜单页 `XSkinMenuTreePage`**（`ui/skin/skin_menu_tree_page.gd`，extends XSkinTemplatePage）

- 套法（旧页回调一行不改）：

  ```gdscript
  var tree: XSkinMenuTreePage
  # _ready：
  if XUiSkin.on() and <你的卡的开关>:
      tree = XSkinMenuTreePage.new("页名")
      tree.left_icon = 图标号; tree.left_lines = ["小字", …]   # 或 tree.left_draw = func(ctrl, row): 自己画
      tree.currencies = [["名", "数"]]                        # 默认 []＝右上不写
      add_child(tree)
  # choose(rows, ok, cancel, lines, o := {})：照旧记 log，然后
  if tree != null: tree.open(rows, ok, cancel, lines, o); return   # lines 不要先折行
  choice.open(rows, ok, cancel, wrapped)
  ```

- `open(rows, ok, cancel, lines, o)` 的 `o`：
  - `crumb`：面包屑整串（如 `["宝珠坊", "鉴定神秘珠", 名字]`）；只有一段（第 0 层）时不画面包屑（标题已写）。列表标题默认＝最后一段（`list_title` 可改）。
  - `result: true`：结果页：右牌名旧金、牌底「知道了」（＝取消）。
  - `confirm: {title, danger}`：确认页：不换列表，弹统一确认弹窗（钮＝这一层的行，正文＝说明几行换行连起来；title 不给＝第一行字＋「？」；danger 橙边停最后一枚）。
  - `row_view: func(row) -> {text, right, tags, …}`：自己摆一行（不给按 `split_row`：「名 ×N」「…（含数字）」「… → …」挪行尾）。
  - `card_for: func(row) -> Dictionary`：光标那一行自己的右牌（返回 {} 就用说明几行那张）。
  - `hints`：按键提示（默认「确定 选择／取消 离开（第 0 层）或返回」）。
  - `card_button: func(index, row)`：右牌按钮交给页面（天衣铺、器谱加操作钮用）；不给＝按了当取消（结果页「知道了」）。
  - 右牌开着 `fold`：说明太长时牌底「Y 看完整说明」；页面别再占 Y 键。
  - `group_key`：页面建好后、`add_child` 前设（从主菜单哪一组进就挂哪一组；不是从主菜单进留空）。行可用 `label` 或 `text`。
- 和 XChoiceWindow 同名：`rows`、`info`（没折行）、`index`、`ok()`、`cancel()`、`move(d)`、`page(d)`；测试照旧 `tree.index = i; tree.ok()` 就能走（确认弹窗开着时也一样）。系统音同选择窗（换行 0、确定 1、取消 2、不可选 3）。
- 自己收键（`_unhandled_input`）、右键＝取消、左上「‹」＝取消；`current_row()` 是列表光标那一行（弹窗开着时是弹窗背后那一层的）。
- `XSkinMenuTreePage.ENABLED` 是卡 K 的开关（制作也认它）；别的页套用时请另设自己的开关，别借这个。
- 天衣铺（`yunshang`）、屠苏器谱、星谱也是 XChoiceWindow 串联，但不在本卡独占文件里，**没接**；开放时照上面套一遍、各补一张截图即可。

**制作页 `XSkinCraftingPage`**：同商店的做法（旧页 `_refresh` 末尾 `skin.sync()` 并跳过旧窗口；`_unhandled_input` 开头 `skin.input`；`_gui_input` 有新页时直接 return）。`level_parts(s, cat)` 给环下一条的三样（左字、右字、比例）。

## 没做／偏离

- **结果页的行留在列表**：稿写「结果页进右牌＋知道了」。结果页原来的行（得到的宝珠逐个可点看说明＋「返回」）要保持一样（`xiyou_orb_shop_ui` 逐页录的 rows 不变），所以行照旧在列表，右牌写结果标题（旧金）＋「知道了」（＝返回）。
- **宝珠坊的三种确认页也走统一确认弹窗**：稿只写了种族祝福的两种确认页；宝珠坊鉴定、兑换、分解的「确认…／取消」同样是确认页，一起改成弹窗（分解按 3.0「找不回来的操作」橙边、光标停「取消」，鉴定、兑换灰边停「确认」）。种族祝福除稿写的两种外，进阶确认（「确定进阶／返回」）也走弹窗。
- 分解确认默认停「取消」：键盘「确定、确定」不再直接分解（要先左右移到「确认分解」）。这是 3.0 的规矩；旧页（西游、开关关）照旧停第一行。
- 锻造原件行：稿写 64 高两行式；`XSkinList` 没有两行行（不是本卡文件），本卡用一行：名字＋后面小字「品质 · 层数 · 已装备／背包」，放不下时小字先省略。要两行式请给列表组件加 `line2` 行键（归列表那张卡）。
- 右牌「材料」每行没画图标（`XSkinCard` 的 lines 不带图标），只写名字＋「持有 / 需要」。
- 宝珠坊「宝珠纹章」没有美术：先放第一档神秘珠的图标（圆底＋旧金细圈）。制作环 4 球用原类别图标。
- 开局默认页（还没选族）没有选中的队员，左块空着。
- 「一个开关」做成 `XSkinMenuTreePage.ENABLED`，制作也认它（三页一起回退）。
- 旧画法对照只拍 16:9：旧页不铺横屏（没有 `XSkinLayout.request_wide`），1000×450 窗口里画面还是 800×450，拍了也没意义。
- 制作在数量条上按取消：显示的数量复位成 1，XCraftingScene 的 `amount` 照旧页逻辑在下次进数量条时才复位（旧页本来如此），专项核了「再进从 1 起」。
- 环上上下键也能换类别（旧页只认左右）。
- 稿的动效（换分类淡入、数值闪金）没做，同卡 I，归统一动效卡。
- 按住连加、点数字弹键盘没自动测（数量选择是卡 I 的件，卡 I 已测按钮）；测了点数量钮、点主按钮。
