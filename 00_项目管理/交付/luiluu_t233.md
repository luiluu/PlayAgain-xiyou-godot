## 「特殊语义」判据（验收 1）

依据 v0.3 第二节第 1 条（第一批只给「没有任何特殊语义的单体伤害技」打标记）和 v0.3.1 布兰德瓦登「引导」。引导的作用是「把这一招的目标从甲换成引导者」，所以凡是**招式本身不只是『对一个人打一次伤害』、换个目标语义就变、或者结算会牵出别的人／别的流程**的，一律不签。逐条判据（任中一条即不签）：

| 判据 | 例 | 怎么机器判的 |
| --- | --- | --- |
| A 吸血／吸血转移 | 撕咬、嗜血追击、魔吞 | 技能备注带 `<HP Life Steal>`，或序列里给自己回血 |
| B 自定义选目标（多目标、随机目标、换目标逻辑） | 龙息、狂怒冲撞、凝视系 | 备注带 `<Custom Target Eval>`（选两个不同目标） |
| C 触发公共事件、连锁追加 | 炎爆术、风魔炮、踏地 | 效果里有 code 44，或序列有 `COMMON EVENT`；给自己挂「再次释放」(345) |
| D 必中秒杀／移除 | 放逐、苦闷之环、神之制裁 | 附带无法战斗(1)／石化(126)／放逐(263)／伪死亡(1705)；序列里直接 `HP -9999` |
| E 改写行动的控制状态 | 混乱、愤怒、魅惑、致命诱惑 | 附带的状态 restriction 为 1／2／3（强制普攻／攻击任何人／攻击队友）；眩晕、睡眠、麻痹这类「不能动」不算 |
| F 状态有按来源者吸取、害己害人的脚本 | 附骨之疽、破阵附骨之疽、雄的怒吼 | 附带这三个状态号 |
| G 按目标状态变化 | 斩杀、鱼人斩杀、黑虚闪、万剑归一、圣化矛术*极 | 伤害公式读 `b.hp／b.mhp／b.states／b.agi／b.luk`；序列里 `IF TARGET.…` 分支 |
| H 序列实际打整组（不是单体） | 时空断裂等 | 序列里 `ACTION EFFECT: actors／enemies` 指定了组。移植里 `make_targets` 把 `ACTORS` 解析成全体存活我方、`ENEMIES` 解析成出手者自己这一方，每段整组各打一次 `_invoke`（`action_sequence.gd:268-283`）；scope 虽写 1，实际不是单体。**这一类单列「拿不准」**：只靠读代码判的，没在战斗里逐个跑过 |
| I 附带给全体我方加状态／扣血 | 九天净雷、圣之制裁 | 序列里 `ADD STATE …: actors`、`HP -20%: actors` |

**不算特殊语义的**（照签）：附带普通减益（灼伤、碎甲、冰冷、出血、中毒、黑暗、沉默、重伤、眩晕、麻痹、睡眠、气伤等，招式只是附带在这个目标上）；给自己加的增益／动画标记（炽魂、风动、神圣护盾、杀意、防御）；多次 `ACTION EFFECT` 的多段技（v0.3 本来就有多段中途失效规则）；耗 MP／TP、出手速度；伤害公式只读出手者（`a.atk、a.mat、skillMasteryLevel`、`user.elementRate`）。

## 拿不准、没签的（验收 5）

- **判据 H 的 40 个**（理由只有「序列 ACTION EFFECT 指定整组」）：表里判定列写「拿不准」。按移植代码读，它们每段会打整组，不是单体，所以保守不签；但没逐个开战斗验证，也不排除原版里这个写法只是把「目标」指成了整组的别名。要签得先开战斗实测，再回来加号（改一行 `guidable_skills`）。
- **判据 E（混乱／愤怒）**：仅因这条不签的有 8 个（863 摄人心魄、981／985／4036 恶魔印记、1879 愤怒凝视、1880 混乱凝视、3976 魔音穿耳、4238 混乱之雷）。我判不签，因为它们改的是目标的行动归属，和「改目标」叠在一起设计稿没谈过。**但这条是我的判断，不是设计稿原文**——若觉得「只是个减益状态」可以签，改判后加这 8 个号即可。放在「要 Kyo 定」里。
- 伤害公式带随机倍率的 `零时迷子 10015、炎·乱 10016、天破壤碎 10556`：随机倍率（`Math.random`）本身不是目标语义，没作为不签理由；10015、10016 单列「拿不准」（判据 H），10556 另有致命诱惑（判据 E）。
