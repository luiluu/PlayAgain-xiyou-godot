## 一、天衣统一原则

| 条 | 规则 |
| --- | --- |
| 1 算谁的预算 | **按装备口径单独算**，相当于一件专属法宝：没醒 ≈ +10% 强度，醒着 ≈ +20%。不占穿戴者的被动预算（增伤 +50% 等），也不占云裳的预算。云裳的预算只管「唤醒」（敕衣点神、神纹自鸣、天衣无缝、收针）。 |
| 2 稀有效果进全局闸 | 天衣给的再动、多行动、免死，和穿戴者其他来源合计：**每回合最多多 1 次行动**（现有 `cap_actions`）；**免死每场 1 次**（所有来源合计）。超了的那次不发生，不补偿。 |
| 3 醒着不翻倍 | 醒着比没醒多一条机制或一个数，不做「×2」「两路各算一次相加」「每份 2 次」这类翻倍。 |
| 4 伤害口径 | 天衣的伤害一律用穿戴者的主属性和职责浮动，系数按标准档位（普攻 1.0／常规单体 3.0）。不用固定底数。 |
| 5 属性改动 | 只做百分比重分配，净增不超过 +20%；不给固定数值。 |
| 6 不攒伤害 | 删掉所有「储存／债 → 伤害」的转换（口径：不靠挨打攒数值条）。 |
| 7 首领 | 控制、夺增益、转减益对首领：只转普通减益，夺增益每次最多 1 个。 |
| 8 叠放 | 天衣占衣服栏，一人一件；同名天衣全队只算第一件。 |
| 9 醒 | 「醒」＝被唤醒到下一回合末（2 回合），不变。 |

## 三、璇：寄命星灵转伤 20%

附身时璇仍在出战名单、有生命条；敌方单体、群攻都打不到她，附身期间一切扣血被隔离。转伤是**唯一能扣附身中璇生命的路**。

| 项 | 规则 |
| --- | --- |
| 谁转 | **只有主宿主**。星影队友、并轨副宿主不转 |
| 转什么 | 敌方行动对主宿主的直接生命伤害（伤害类型 1／5）。持续伤害、自己付的代价、队友误伤不转 |
| 取哪个量 | 主宿主算完防御、减伤，**护盾吸收之后**、扣血之前的量 X |
| 转多少 | T＝X × **20%**，取整。主宿主扣 X−T |
| 璇这边 | T 直接扣璇生命，**不算璇的防御、减伤，也不吃璇身上的护盾**（防御已在宿主那边算过）。绕过附身的扣血隔离 |
| 每回合上限 | 一回合内转给璇的合计 ≤ **璇生命上限 10%**，超出的留给宿主 |
| 保底 | **璇生命低于上限 30% 就不再转**（这一下照算到 30% 为止）。所以转伤不会打倒璇，也不会打断附身 |
| 璇倒下 | 只可能来自别的路（脚本扣血等）：照现有规则解除附身，宿主失去共宿等效果 |
| 列星 | 列星期间仍只转主宿主，全队变星影也不会多转。不存在「列星把璇秒掉」 |
| 显示 | 宿主头上照常弹扣血数；璇头上弹「星承 −T」 |

**20% 合不合适**：合适，但必须带上限。没上限时相当于宿主常驻 −20% 受伤，再叠共宿双防偏强；加「每回合 ≤10%」和「低于 30% 停」后，长期最多替宿主吃掉璇约 70% 生命，强度≈一次 20% 护盾外加一点，和辅助预算对得上。

### 回光对星影

| 目标 | 回复 | 净化 |
| --- | --- | --- |
| 回光选的原目标（含主宿主） | 生命上限 **30%** | 一个控制 |
| 列星扩展进来的其他星影 | 生命上限 **10%**（全体治疗档） | 不净化 |

璃壁同理：原目标 20%，扩展的星影 5%（已定）。

## 四、甚尔：免费切换与天逆鉾

### 每回合第一次切换不耗行动

| 项 | 规则 |
| --- | --- |
| 「每回合」 | 自然回合：回合开始时重置「本回合已免费切换」标记。没用不累积 |
| 怎么生效 | 本回合还没免费切过时，选切换技能**立即换形态**，不进行动队列，回到甚尔的指令输入，接着选这次真正的行动（普攻） |
| 同回合再切 | 可以，但**耗一次行动**（照原版：行动结束后换形态） |
| 算不算行动 | **不算**。不触发武器库、黑闪（不判、不加集中、不断连闪）、再动 10% 判定；不进行动次数，不吃天衣的行动类效果 |
| 沉默（技能封印） | 能用：切换本来豁免战技封印，免费那次照旧 |
| 被控制 | 不能行动（眩晕、冻结、睡眠等）时没有指令输入，**不能切**。混乱、魅惑等自动行动时也不切 |
| 天逆鉾封印到自己 | 免费切换不是主动技能，不触发失效；付费切换照原版算主动技能 |
| 再动多出的那次 | 同一回合，标记不重置：再动那次只能付费切 |
| 自动战斗 | 轮到甚尔时，按当前目标估四种咒具普攻的伤害（含溅射、穿透）；**比当前形态高 20% 以上**才免费切过去，再普攻。对首领、且目标身上没有「天逆」、离上次生效满 3 回合时优先切天逆鉾。自动战斗不做付费切换 |
| 智能 AI 档案 | 免费可用时切换的「铺垫」记 0 次行动，不再记 1 次 |

### 天逆鉾

| 项 | 普通敌人 | 首领 |
| --- | --- | --- |
| 效果 | 目标下一次主动技能失效（已定） | 目标下一次**伤害行动伤害 −30%** |
| 持续 | 生效一次就去掉；没生效到**下一回合末**也去掉 | 同左 |
| 次数 | 1 次。**觉醒不再给 2 次** | 1 次 |
| 限制 | 同一目标 **3 回合内只生效一次**：从附上那一刻算，不论有没有被消耗；武器库追击的天逆鉾共用这一限制 | 同左 |
| 首领判定 | 照现有首领名单（`XEnemy.boss_id`） | — |

**理由**：−30% 一次、每 3 回合一次，平均约 −10%，正好是对敌减益档。
