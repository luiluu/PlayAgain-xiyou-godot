### 丁 神功扣费后变量负数归 0（`ce2500`）

先说清楚：`ce2500` 开头 `v752 = v206 / 30`（向下取整），每档门槛 `v752 ≥ N` 后扣 `30N`，扣完不可能小于 0，所以 11 处「v206 < 0 → 0」里有 10 处原版走不到。唯一走得到的是 10588 档学完马上又满足 10589 档（两档嵌套、v752 只算一次）：扣 3000 再扣 15000，v206 < 18000 就会变负再归 0。已有的 `sa4d_35`（v206＝15000）就走到了这一处，但它的结果「归 0」和「刚好扣到 0」分不出来。本单补的是扣费边界和一个分得出归 0 的例：

| 用例 | 预设 | 预期 |
| --- | --- | --- |
| ce2500#gate1_24 | 会 10113，v206＝629 | 「学习成功！」；206 −600（剩 29）；752 +20；学会 10579 |
| ce2500#gate1_25 | 会 10113，v206＝599 | 无提示；只有 752 +19（599/30 向下取整到 19，不到 20） |
| ce2500#gate1_26 | 只会 10587，v206＝1529 | 「学习成功！」；206 −1500；752 +50；学会 10588 |
| ce2500#gate1_27 | 只会 10587，v206＝1499 | 无提示；752 +49 |
| ce2500#gate1_28 | 只会 10588、10589，v206＝17999 | 两次「学习成功！」；206 −17999（−1 归 0）；752 +599；学会 10590、10591 |

gate1_28 是关键：重制没归 0 的话 206 会是 −18000。
