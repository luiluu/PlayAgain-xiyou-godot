## 一、角色卡

### 轮回者·里德｜超强者｜均衡型：一招英勇打击，按六道转着打

- **立意**：品质最低的初心者，走完一整轮回来了。他还是只会英勇打击这一招，但这一招现在按六道转着打。原版「轮回归来」里，里德本来就是跟着轮回的那个人。
- **职责**：均衡型（伤害 ×1.0，生命 ×1.0）。主属性物攻，伤害＝物攻×系数（满级值）。超强者 +150% 由系统给，不写进卡。
- **核心机制「六道轮盘」**：
  - 轮盘上有六道，顺序固定：人道 → 畜生道 → 饿鬼道 → 修罗道 → 地狱道 → 天道 → 回到人道。
  - 指针指着「下一下要打的那一道」。普攻指令就是英勇打击，打的是指针指着的那一道；打完指针往前走一格。
  - 每打出一次天道，算**转完一轮**，得 1 层轮回。
  - 不攒数值，不靠挨打。玩法是看着轮盘排招：知道下一下是什么，决定打谁、要不要「定」住或「转」过一格。

| 技能 | 习得 | 效果 |
| --- | --- | --- |
| 英勇打击·人道 | 1 级 | 常规，单体 3.0。全队 TP +10。 |
| 英勇打击·畜生道 | 1 级 | 常规，两段共 3.0（各 1.5）。第二段打另一个敌人（只剩一个时打同一个）。 |
| 英勇打击·饿鬼道 | 1 级 | 常规，单体 3.0。伤害的 30% 回给自己，最多回生命上限 10%。 |
| 英勇打击·修罗道 | 1 级 | 爆发，单体 6.0。这一下必定暴击。 |
| 英勇打击·地狱道 | 1 级 | 爆发，全体 3.0。附灼烧：每回合失去生命上限 5%，2 回合（首领 1 回合）。 |
| 英勇打击·天道 | 1 级 | 大招，单体 9.0；全队回复生命上限 10%。转完一轮。 |
| 英勇打击·天道（满层） | 轮回 3 层 | 满 3 层后，天道在技能列表里多一招：全体 5.0（回复照旧）。单体 9.0 和全体 5.0 二选一。 |
| 轮回 | 1 级（被动） | 每转完一轮得 1 层，最多 3 层。每层英勇打击六式伤害 +10%（满层 +30%）。 |
| 定 | 10 级 | 这一下照常打指针指的那一道，打完指针不动（下一下还是这一道）。只能用在人道、畜生道、饿鬼道、地狱道。冷却 3。 |
| 转 | 30 级 | 跳过指针指的那一道，直接打下一道，打完指针停在被打那一道的下一格。指针在天道时不能用（天道不能跳）。冷却 3。 |
| 转世 | 50 级（被动） | 倒下时如果至少有 1 层轮回：消耗 1 层，回复生命上限 30% 站起来，指针回到人道。每场一次。 |
| 决心 | 1 级（被动） | 生命、物防、魔防、敏捷、幸运 +5%（不含物攻、魔攻）。 |
| 战术 | 15 级（被动） | 战斗外可以选开场从哪一道起手（人道到地狱道，不能选天道；默认人道）。 |
| 初心 | 20 级（被动） | 能装备任何类型的武器和防具。 |
| 四小强之魂·轮回 | 50 级（被动） | 他算一名四小强（修、罗琳、美娜的四小强之魂把他算进人数）。天道回复时，四小强同伴各去掉一个负面状态。 |

**定和转都不占行动**：它们不是单独的一步，而是英勇打击的两种打法。技能列表里同时列出可用的几种，选哪个就是这回合的行动。一次行动只能用定或转其中一个。

**进阶四次**（每次另学通用的超越极限 I～IV，增伤 +5%）

- 一～三：只有 +5%，没有别的机制（照底稿；要加可以从第四节挑）。
- 四「昂首·轮回」：英勇打击六式必中。

**专属法宝「六道木剑」（暂名）**：每场战斗开局自带 1 层轮回。

**怎么打**：一轮是 人 → 畜生 → 饿鬼 → 修罗 → 地狱 → 天，六下合计系数 27.0。打首领时用「转」跳过人道、「定」把地狱道再打一次（灼烧刷新）或把饿鬼道再打一次（回血）。打小怪时「定」住地狱道连打两次全体。开场带法宝 1 层，再转两轮满层，天道就能选全体 5.0。

**强在**：输出稳，什么时候出大招全看得见；转世每场能多扛一次；初心穿什么都行，养成简单。**弱在**：前几下都是常规档，开场爆发低；转世要吃掉 1 层轮回，等于掉 10% 伤害；定、转用错一次，天道就晚一回合。

**说明卡示例**

```

```

```

```

```
效果：这一下打当前这一道，打完轮盘不转

冷却时间：3回合
```

```
转

```

## 二、实现细则

### 1. 编号和数据（照五条悟 `XGojo` 的写法）

- 新角色、新职业，原版档里不出现：天启篇以外停用、图鉴和仓库不列（同 `XGojo.hidden`）。
- 建议编号（实装时按空号定，被正式源占用就整体挪）：角色 181，职业 179，技能 10651 起，状态 2801 起。
- 六式是 6 个技能号；满层天道全体另 1 个号；定、转各 1 个号（列表里显示成「定·饿鬼道」「转→天道」）。
- `<Replace Attack>` 指向当前这一道（照甚尔的「普攻＝当前形态主技能」）。战斗技能列表只列：当前这一道、可用时的「定·这一道」、可用时的「转→下一道」；满层且指针在天道时多列天道全体。
- 系数、冷却、说明写进 `skill_rework.json`，模块名 `reid`（同 `gojo`）。

### 2. 轮盘状态存在哪

- 战斗内临时数据，按角色存（同 `XGojo._temp`）：`{wheel: 0～5, layers: 0～3, reborn_used: false}`。`wheel` 是指针（下一下打哪一道）。
- 战术选的起手道存在角色身上，跟存档走：`flags.tianqi.reid_start`（0～4，默认 0）。

### 3. 什么时候变

| 时机 | 指针 | 轮回层数 |
| --- | --- | --- |
| 开战 | 设成战术选的起手道 | 0；带六道木剑为 1 |
| 打出一招（普通） | 前进一格 | 打出天道时 +1（最多 3） |
| 用「定」 | 不动 | 不变（定不能用在天道） |
| 用「转」 | 跳到被打那一道的下一格 | 被打的是天道时 +1 |
| 眩晕、睡眠等没行动 | 不动 | 不变 |
| 沉默（封技能） | 普攻照打、照转；定、转用不了 | 照常 |
| 混乱、魅惑等失控 | 不动 | 不变（失控时打的是不带六道的英勇打击：单体 3.0） |
| 换下场（和助力位换人） | 保留 | 保留（下场期间不打，不变） |
| 倒下，触发转世 | 回到人道 | −1 |
| 倒下，没转世 | 回到人道 | 保留（被别人复活后接着用） |
| 战斗结束 | 清掉 | 清零 |

### 4. 先后顺序（一次行动内）

1. 玩家选招：普通／定／转。定、转在这一步就决定了打哪一道。
2. 结算伤害。层数加成用**出手前**的层数（打出天道这一下不吃它自己加的那一层）。
3. 结算这一道的附加效果（TP、吸血、灼烧、回复、去负面状态）。
4. 打出的是天道：层数 +1（满 3 不再加）。
5. 移动指针：普通前进一格；定不动；转停在被打那一道的下一格。
6. 刷新显示状态（下一道、层数）。

回答底稿里的几个问题：

- **定和自动转谁先**：定只是让第 5 步不动，自动转被它取消。
- **转跳过的那道算不算**：不算打过（没伤害、没附加效果），但这一轮照样能转完，因为一轮只看「有没有打出天道」。
- **转能不能跳天道**：不能。所以一轮一定会打出天道，层数不会白拿。
- **同一回合先定再转**：不行，一次行动只能用一个。测算过，放开也不会更强（见第三节），只是界面更乱。
- **层数什么时候生效**：从下一招开始。

### 5. 层数每场清零（默认）还是跨战斗（可选）

- **默认：每场清零**（底稿）。每场从 0 层（带法宝 1 层）开始，转世也要先打出一轮才有。
- **可选：跨战斗**。层数留到离开本层楼（或回大厅）才清零，累计封顶仍是 +30%。这样大部分战斗一开场就满层，转世也一直在，等于常驻 +30%，「转一轮变强」的感觉就没了。还要把六道木剑改成别的效果（比如「转世后指针不回人道，停在倒下时那一道」）。**不推荐**。

### 6. 界面

- **身上的状态图标**（第一期就做，同五条悟的苍印、赫印）：
  - 「下一道：人道」～「下一道：天道」六个显示状态，同时只挂一个，图标是那一道的图标。
  - 「轮回·一」～「轮回·三」三个显示状态，挂当前层数那一个。
  - 都是战斗结束去掉、不能被驱散的祝福类。
- **轮盘小图**（第二期）：战斗状态栏他那一格旁边放一个六格小轮盘，当前这一道亮着，下一道描边，三颗小珠子亮几颗就是几层。
- **技能列表**：每一招名字带道名，说明里写「打完转到 ×× 道」。
- **战斗文字**：
  - 转完一轮：「里德转完一轮，轮回 2 层。」
  - 满层：「轮回三层已满，天道可以普照全场。」
  - 定：「里德定住了轮盘。」
  - 转：「里德转过了饿鬼道。」
  - 转世：「里德倒下了……又从人道站了起来。」

### 7. 自动战斗和敌人

- **自动战斗、挂机**：只用普通打法。可用时按简单规则用定、转：指针在人道且转可用就转；指针在地狱道、敌人 2 个以上且定可用就定。满层天道：敌人 2 个以上打全体，否则单体。
- **敌人用他的技能**（以后有镜像类敌人时）：按顺序六道，不用定、转，层数照算，天道回复给敌方全体。
- **敌人怎么对他**：不加特殊仇恨，不改敌人 AI。

### 8. 和原版里德、四小强、超强者上限

- **和原版里德不能同队**：抽阵容时 11 和 181 互斥（`roll_lineup` 抽到一个就把另一个移出候选；`lineup_ok` 两个同在算不合法）。
- **四小强**：他算一名四小强。修、罗琳、美娜的四小强之魂（每多一名 +5%，最多 +15%）把他算进人数：`actors` 里 8、9、10 的 `ids` 加 181。因为不能和原版里德同队，人数不会多算。他自己不吃四小强之魂的增伤（他的增伤走轮回层数）。
- **原版里德**：照旧在四小强里，按弱者（Kyo 定）。抽阵容时原版里德占弱者位，轮回者占超强者位，两人互斥。
- **超强者上限**：他算超强者，占上限：寻常、艰险抽不到，九死最多 1 名超强者，炼狱 2，证道 3。不是成长型，一开放就是超强者。
- **档位名单**：`tiers.超强者` 加 181，名单到 17 人（五条悟 180 进名单后 18 人）；`tiers._note`「11 里德在第七期改成轮回者·里德」的说法要改成「轮回者·里德是新角色 181，11 不动」；`天启篇数据校验.py` 的超强者人数检查跟着改。

## 三、数值核对

### 1. 每招档位（均衡型 ×1.0）

| 招 | 本卡 | 档位上限 | 说明 |
| --- | --- | --- | --- |
| 人道 | 单体 3.0 | 常规单体 3.0 | 合 |
| 畜生道 | 两段共 3.0 | 常规单体 3.0 | 合 |
| 饿鬼道 | 单体 3.0＋吸血（最多 10%） | 常规单体 3.0 | 合 |
| 修罗道 | 单体 6.0，必暴 | 爆发单体 6.0 | 必暴算进暴击预算，见第 3 条 |
| 地狱道 | 全体 3.0＋灼烧 | 爆发全体 3.0 | 合；灼烧按首领减半 |
| 天道 | 单体 9.0＋全队回 10% | 大招单体 9.0、全体治疗 10% | 合 |
| 天道（满层） | 全体 5.0 | 大招全体 5.0 | 合 |

修罗、地狱、天道没有冷却，是靠轮盘限次数：不用定、转时每 6 下各出一次，比爆发要的冷却 3、大招要的冷却 6 都不短。

### 2. 一轮的输出（内部测算，不给玩家看）

按「打首领、只算系数」，用动态规划算长期每次行动的平均系数。参照是标准循环（1 大招＋2 爆发＋3 常规）＝每下 5.0。

| 规则 | 每下平均 | 对标准循环 |
| --- | --- | --- |
| 不用定、转 | 4.5 | 90% |
| 底稿：定、转各冷却 3，不限道 | 5.75 | 115% |
| 底稿，修罗必暴按 1.5 倍算 | 6.53 | 131% |
| **本稿：定不能用在修罗、天道；转不能跳天道** | **5.0** | **100%** |
| 本稿，修罗必暴按 1.5 倍算 | 5.67 | 113%（多的部分在暴击预算里，见下条） |

- 底稿的问题：定能把天道、修罗道连打两次，转能把人道、畜生道跳掉，最好的打法是「天道打两次＋跳过常规道」，比标准循环高 15%（算暴击 31%）。
- 改法：定只能用在常规的四道；转不能跳天道。这样定、转的用处是「多打一次地狱（清怪、续灼烧）」「多打一次饿鬼（回血）」「跳过人道早出天道」，刚好回到标准循环。
- 定、转放开同一次行动一起用，算出来也是 5.0，所以一次只能用一个不影响强度，只为界面简单。

### 3. 修罗道必定暴击

- 暴击倍率底数 1.5，修罗 6.0 必暴实际是 9.0，等于又一个大招。
- 本稿按「暴击预算」算它：六下里一下必暴，平均暴击率约 +17%；转跳过一格时一轮五下，最多 +20%。在「暴击 +20% 以内」里，所以**卡上不再给任何暴击加成**。
- 也因此定不能用在修罗道（不然一轮两下必暴，超暴击预算）。
- 如果 Kyo 觉得必暴不该占暴击预算，改法是修罗道系数降到 3.6（必暴后实际 5.4，在爆发 6.0 内）。

### 5. 底稿里改了的地方

1. **定、转加限制**（上面第 2 条）：定只能用在人、畜生、饿鬼、地狱；转不能跳天道。底稿不限，强度到 115%～131%。
2. **一轮怎么算**：改成「打出天道就算转完一轮」。底稿「六次转完」在定、转之后数不清楚，现在不用数。
3. **人道、畜生道的回 TP**：他没有耗 TP 的招，回给自己没用；改成 TP 当燃料（定、转耗 TP）测过，受伤也回 TP，等于靠挨打，不用。改法：人道给**全队** TP +10（给同伴的 TP 大招用）；畜生道去掉回 TP，第二段打另一个敌人（清怪时有用）。见问题 3。
4. **饿鬼道吸血加上限**：伤害的 30% 打首领时可能一下回满，加「最多生命上限 10%」。
5. **地狱道灼烧对首领**：规则要求按生命百分比的伤害对首领减半，改成首领只烧 1 回合（不写 2.5% 这种数）。
6. **满层天道**：底稿是「变成全体 5.0」，打首领时从 9.0 掉到 5.0，满层反而变弱。改成满层后多一招全体 5.0，和单体 9.0 二选一。
7. **决心**：原版全属性 +5% 含物攻，等于再加 5% 增伤，增伤会到 55%。改成不含物攻、魔攻。
8. **四小强之魂**：底稿「每有一名，天道回复 +5%，他们各得伤害 +5%」：回复最多到 25%（超全体 10%），伤害按人数叠（超全队增益一项 5%），还和他们自己的四小强之魂重复。改成「他算一名四小强」（同伴原有的四小强之魂自动算上他）＋「天道去负面状态」，不加新数值。
9. **战术起手不能选天道**：不然每场第一下就是大招，还白拿 1 层。

1. **四小强连携**：每转完一轮，场上四小强同伴的 30 级爆发技冷却 −1。改动：天道结算后，对场上的修、罗琳、美娜的 10701～10703 冷却减 1。

## 五、开放条件

Kyo 定的两条都要满足：① 通关炼狱时，队伍里用的是里德（原版 11）；② 进入轮回。开放后全存档有效（照五条悟「最强之名」），候选池里出现轮回者·里德（九死起才抽得到超强者）。

### 记录一：「里德走完一轮」（各方案共用）

- **什么时候判**：36 层骑士本体决战打赢那一刻（`XTianqiLine.run_final` 里写「可轮回」的同一处）。

- **玩家看到**：结局结算时多一行「里德走完了一轮。」读档界面这一档的「可轮回」后面加「·里德」。

### 记录二：「进入轮回」（三选一）
