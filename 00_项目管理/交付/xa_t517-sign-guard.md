## 变更记录草稿

## 2026-11-25 【小A·T517·未经审查】发布补丁／生成更新清单 `sign()` 强制关键字参数与防覆写私钥硬守卫（dev.待定）

- 原因：原 `sign(key, data, sig)` 接受位置参数且直接把 `sig` 交给 `openssl dgst -out`，若参数传反（把私钥路径传到第 3 位），`openssl` 会在解码报错前就将私钥截断为 0 字节（2026-11-25 事故复盘）。
- 改动（[发布补丁.py](03_再刷重制_Godot/07_开发环境/发布补丁.py)、[生成更新清单.py](03_再刷重制_Godot/07_开发环境/生成更新清单.py)）：
  - `sign(*, key: Path, data: Path, sig: Path)` 改为**强制关键字参数**，两处内部调用均改为 `sign(key=..., data=..., sig=...)`，从语言层杜绝传反参数。
  - 调用 `openssl` 前执行多重硬守卫：① 拒绝输出路径带 `.pem/.key/.keystore/.p12/.pfx/.jks` 后缀；② 拒绝输出路径含 `发版密钥` 目录段或落入 `~/Library/Application Support/KYO/发版密钥` 下；③ 拒绝 `sig` 与 `key` 或 `data` 同路径（含 `resolve()` 后）；④ 校验 `key` 非空且开头为 PEM `PRIVATE KEY`、`data` 非空且非私钥。
  - 签名改先写入 `sig` 同目录临时文件，校验 `openssl` 退出码为 0 且非空后再 `os.replace()` 原子替换 `sig`；任何失败自动清临时文件，绝不截断目标文件。
- 单元测试（[测试发布补丁.py](03_再刷重制_Godot/07_开发环境/测试发布补丁.py) 28/28、[测试生成更新清单.py](03_再刷重制_Godot/07_开发环境/测试生成更新清单.py) 14/14）：覆盖位置参数拦截、敏感后缀与 `发版密钥/` 目录拦截、同路径拦截、非私钥/损坏私钥/对私钥签名拦截、失败不截断已有文件、正常按名传参签出并验签通过。
- 玩家可见：无（仅开发环境发版工具加固，不影响游戏行为）。
