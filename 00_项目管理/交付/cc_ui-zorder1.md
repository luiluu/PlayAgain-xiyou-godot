## 2026-11-10 【cc·白龙·未经审查】战斗自动／变速按钮被淡出黑幕盖住；地图事件淡出的黑幕挪到窗口之下、跟场所移动的黑幕分开（dev.待定）

- 起因：审查 75 P3-2，rules-gaps11 车道截图里战斗的「自动／变速」按钮露在事件淡出（221）的黑幕上。原版没有这两个按钮（O-006 重制新增），黑幕（Spriteset_Base._fadeSprite）之上只剩窗口。
- 战斗：两个按钮从 `ui` 挪进新的 `low_ui`（`battle_scene.gd`），放在战斗画面（背景、战斗者、伤害数字、连击数）之上、`screen_fx` 之下，所以 221 的黑幕和闪烁都盖住它；不随行动序列镜头和胜利镜头移动，胜利时跟窗口一起藏。开战淡入的黑幕（z 100）本来就盖住全部，没动。按钮点击不受影响（上面的 ui 层都不拦鼠标）。
- 同类问题，地图（`map_scene.gd`）：原来事件 221／222 和场所移动共用一块黑幕，它排在消息窗之后，所以：
  - 「淡出后在黑底上显示文字、选项」的事件，重制里文字和选项被黑幕盖住看不见。现有数据里有 1 处：欧皇活动 CE1433（淡出后连着 6 条文字和「赢下所有」选项）；
  - 221 淡出之后场所移动，移动结束的淡入会把 221 的黑也掀掉（原版 $gameScreen 亮度不受移动影响，要等 222）；
  - 场所移动时地图按钮（备份、传送、回大厅）和挂机提示露在黑幕上（原版 Scene_Base._fadeSprite 建出时加在场景最上，全盖住）。
  现在拆成两块：`screen_fader`（221／222，`fade()`）放在 ui 最底、消息窗和地图按钮之下；`fader`（场所移动，新函数 `transfer_fade()`）单独一层 CanvasLayer 80，盖住 ui（10）里的一切，成就弹窗（85）、提示（XToast 90，原版网页层）和触屏按键（120）仍在它上面。解释器照旧调 `host.fade`，不用改。
- 查过没问题的：战斗里别的 ui 层（Boss 血条、日志、状态、行动顺序条、说明卡、Boss 状态面板、消息窗）都是原版窗口层的东西，本来就该在黑幕之上；挂机快捷界面（XdRs_HangUp，原版加在场景上）在黑幕之上也对；地图闪烁（CanvasLayer 5）在 221 黑幕之下，同原版先画闪烁再画黑幕。
- 测试：`xiyou_battle_ui` 加 `auto_speed_under_screen_fx`；`xiyou_transfer` 加 `fade_layers`、`screen_fade_out`、`screen_fade_kept_across_transfer`、`screen_fade_in`。
- 玩家可见：战斗里事件淡出时左上的「自动／变速」按钮跟画面一起变黑；地图上「淡出后显示文字」的剧情（欧皇活动）能看到文字和选项；场所移动时地图按钮也被黑幕盖住。
