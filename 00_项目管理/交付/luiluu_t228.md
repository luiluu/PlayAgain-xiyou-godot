## 影响（转 Kyo 知会）

- **语义变了：固定加减 → 按自己的比例加减。** 同一个状态，属性高的人加得多、减得多，属性低的人加得少、减得少（例：终焉攻击 −1000 → −54%，攻击 3000 的人减 1620，攻击 1000 的人减 540）。原版是人人一样 −1000。
- **比现在（期四开着、照原数）更重。** 派单的前提是「期四后这些绝对值占比远大于原版」，实测反过来：期四开着时 81 级基准队攻击中位 3766，原量级（dev.743）只有 1493。13 层（35 级）期四 2276、原量级 814。所以现在固定值反而显得轻；换成百分比以后，以 81 级为基准跟原版持平，比现在重。
- **58 个状态有某项 ≤ −100%**，挂上就把那一项清到下限（例：灭绝、终焉的幸运 −177%、−355%，诅咒、无望的防御）。原版 81 级基准队挂这些也是扣到 0 附近，协调已定幸运照原版扣到 0、不另处理。
- **极端值**：几个原数特别大的，换算后几十到上千倍（一叶遮目 敏捷 +1000000 → +121359%，黄庭经 +12000 → 攻击 +647%、幸运 +4255%，终算 魔法 +100000 → +2290%）。原版里它们本来就是「顶满」用的，换算后照样顶满（param_max 夹值），行为不变。
- 领域那几个（灭绝 696、终焉 698、眷顾 691、祝福 686、霸者 1106／1110）照口径一起换了，没特调；T229 把领域在天启篇关掉以后它们不会上身。
