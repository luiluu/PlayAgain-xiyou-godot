## 最大生命变化时当前生命：规则清单（只读排查，没改任何代码）

**主规则：保值再夹到上限（截断，不按比例）。** 位置 `modes/xiyou/core/resource_context.gd:352`（`refresh` 里 `clampf(b.hp, 0, b.mhp)`）。装备换了、状态／强化加减、升降级、职业改变，凡走 `refresh_resources` 的，都是：上限变大当前生命不动，上限变小当前生命被压到新上限。

按场景：

| 场景 | 位置 | 规则 |
| --- | --- | --- |
| 穿脱装备 | `core/equipment.gd:126`（`a.hp = minf(a.hp, a.mhp)`） | 保值＋截断（与主规则同） |
| 装备强化／镶嵌／熔炼 | `core/gear_upgrade.gd:40`、`core/growth_forge.gd:189` | 保值＋截断 |
| 事件加减能力值（XParamPlus） | `core/mv_event_core.gd:446` | 保值＋截断 |
| 加减状态（含 buff 类状态） | `core/battler.gd:586、646` → `resource_context.gd:352` | 保值＋截断 |
| 升降级、转职 | `core/actor.gd:361、508-523、134-148` → `refresh_resources` | 保值＋截断（升级本身不回血，同原版） |
| 战斗结束 | `battle/battle_logic.gd:4016` | 保值＋截断 |
| 谷雨储备／封顶锁 | `core/guyu.gd:467、479、579、800`；`core/alien_battle.gd:1586` | 保值＋截断 |
