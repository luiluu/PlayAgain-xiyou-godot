# 跨平台适配（PC＋安卓）

Kyo 2026-11-05 定：重制在 Mac 之外加 Windows（PC）和安卓。本篇是盘点、一期（Windows）做了什么、二期（安卓）怎么做。cc（BA）2026-11-05 写，未经审查。

参照：原版 v0.62.09 二合一包 `再刷西游_v0.62.09_安卓pc通用.apk`（只读解到临时目录看，没运行）。原版是 RPG Maker MV（网页技术），一个包两用：安卓直接装 apk（WebView 套壳＋`AndroidInterface` 原生接口），Windows 把后缀改 zip 解压后跑 NW.js 的 `Game.exe`。`index.html` 按 `typeof nw` 选载 `windows-*.js` 或 `android-*.js` 两套适配层。

## 一、盘点表

| 项 | 原版做法 | 重制现状（一期前） | 要做什么 |
| --- | --- | --- | --- |
| 平台判断 | `index.html` 看有没有 `nw`／`require`，选 `windows-preload.js`＋`windows-integration.js` 或 `android-preload.js`＋`android-integration.js` | 只有测试环境变量和 `OS.has_feature("template")`（JSON 缓存位置），没有按平台分支 | Godot 用 `OS.has_feature("macos"/"windows"/"android"/"mobile")`；一期只在全屏键用到，二期安卓集中放一个平台模块 |
| 存档位置 | Windows：`%LOCALAPPDATA%\再刷一把 1.57\save`（不随游戏文件夹覆盖，附「打开存档文件夹.cmd」），首次启动可把包内 `save/` 旧档单向导入一次；安卓：WebView 本地存储＋原生 `readaux/writeaux`，标题「存档工具」导入导出 JSON | `user://`＋`config/custom_user_dir_name="KYO/再刷重制_开发"`：Mac `~/Library/Application Support/KYO/再刷重制_开发`，Windows 自动是 `%APPDATA%\KYO\再刷重制_开发`，安卓是应用私有目录 | Windows 不用改（Godot 自动按平台）；目录名里的「_开发」发行时要不要改是另一件事（见「需要定的」）。不迁移原版存档（底线规则照旧）。安卓二期加「导出／导入存档」走系统文件选择器 |
| 窗口与分辨率 | NW.js 窗口 1280×720、最小 640×360、居中；安卓 WebView 全屏，`Yanfly.updateResolution` 关掉 | 逻辑 1280×720、`canvas_items`＋`keep`；`WindowFit` 按屏幕可用区 90% 定窗口，Retina 物理像素已处理 | Windows 不用改（`screen_get_usable_rect` 在 Windows 也是物理像素，Godot 4 默认开 DPI 感知）。安卓二期：`keep` 会在 19.5:9 手机上留黑边，改 `expand` 要先看各界面能不能跟着宽，先只做 `keep` |
| 全屏切换 | NW.js 默认（F11 等）；`My_DisableFunctionKeys` 屏蔽 F2～F4、F5、F12 | F11 或 ⌘Enter（写死 `meta_pressed`、地图里写死 `KEY_META`） | **一期已改**：macOS 照旧 ⌘Enter，Windows／其它是 Alt+Enter，F11 各平台都认 |
| 按键 | `YEP_KeyboardConfig`、`MK_Sanfu_KeyConfig`、`YEP_ButtonCommonEvents`（按键调公共事件，如 `~`、1～3）、挂机 G 键 | 照 MV 的动作映射；Mac 没有专门按键 | Windows 同键盘，无需改。重制里屏蔽 F 键的事暂不需要（Godot 不会被 F5 刷新） |
| 触屏（地图） | 安卓：自绘摇杆／方向键、确定、取消、跑步、快存、工具栏（`android-integration.js`）；`Codex_AndroidTouchSettings` 调大小、透明度、位置、A-B／全键布局、地图点按开关、战斗点按开关；可选原版 `Mehmet_GhostButtons` 虚拟按钮 | 地图有 `InputEventScreenTouch` 点按走到目标（`mv_player.gd`）、战斗有点按（`battle_scene.gd`），没有虚拟按键 | 二期：做一个虚拟按键层（摇杆＋确定／取消／跑步，可隐藏），设置里调大小与透明度；先不做位置拖动和原版按钮样式 |
| 返回键 | 安卓返回键＝取消（发 `escape` 120 毫秒）；反馈窗打开时先关反馈窗 | 无 | 二期：`NOTIFICATION_WM_GO_BACK_REQUEST` 转成 `ui_cancel`；标题画面按返回问是否退出 |
| 退出 | 安卓 `SceneManager.exit` → `closeapp`；Windows 关窗口 | Godot 默认关窗口 | Windows 不用改；安卓二期标题「退出」调 `get_tree().quit()` |
| 切后台 | 安卓：切后台暂停场景、静音、松开所有触屏键；可选「后台挂机」用前台服务（通知栏常驻＋停止按钮）按真实时间继续跑；回前台恢复音频 | 无（Mac 切走窗口照常跑） | 二期：`NOTIFICATION_APPLICATION_PAUSED/RESUMED` 暂停与恢复、松开虚拟键。后台挂机要写安卓原生服务插件，单独立项（需要 Kyo 定要不要） |
| 音频 | 安卓 WebAudio 被挂起时第一次点屏恢复；回前台修 MV 淡出残留的主音量 | Godot 音频，平台无关 | 二期验证切后台回来有没有声音，Godot 一般自己处理 |
| 字体 | `Codex_ComfortFont_Performance` 载入 `StarComfortUI.ttf`，中文回退链；`YEP_LoadCustomFonts` | 字体打进包里（导出冒烟已验中文换行与字形） | Windows 不用改（不依赖系统字体）。安卓同 |
| 性能 | `Lock60fps`（锁 60 帧）、挂机寻敌线性扫描；安卓专用的不多 | `gl_compatibility`（移动端同），`import_etc2_astc=true` 已开 | Windows 不用改（兼容渲染器走 OpenGL 3.3）。安卓二期在中低端机上量帧率，必要时锁 60 帧 |
| 联网 | 安卓原生 HTTPS 只给反馈服务用；Windows／安卓都有游戏内在线更新 | 没有联网功能 | 不做（发布与更新方式另定） |
| 权限 | 安卓：联网、前台服务（后台挂机）、通知、保持唤醒 | 无 | 二期默认不要权限；做后台挂机才加 |
| 导出 | 二合一 apk（安卓文件＋NW.js 运行时同包） | 只有 macOS 验收、macOS 发行两档预设 | **一期已加** Windows 验收、Windows 发行两档。安卓预设二期加；不照原版做二合一（Godot 两个平台各一个包更清楚） |

## 二、重制里平台相关的代码（一期前）

查了 `OS.has_feature`、`OS.get_name`、`user://`、输入修饰键、窗口模式、`OS.execute`／`shell_open`、触屏事件、导出排除：

- 写死 Mac 的只有两处，都是全屏组合键：`core/window_fit.gd` 的 `is_fullscreen_shortcut`（`meta_pressed`）、`modes/xiyou/map/mv_player.gd` 轮询确定键时排除 `KEY_META`。一期已改成按平台。
- `user://` 全走 Godot 自己的平台目录，没有写死 `~/Library`；`xdb.gd` 的 JSON 缓存在导出包里用 `user://`，平台无关。
- 没有 `OS.execute`、`shell_open`、外部程序调用。
- 导出排除只写在 `export_presets.cfg`，Windows 两档照 macOS 两档抄（验收留 `tests/`，发行排除）；`测试导出过滤.py` 已加上 Windows 两档。

## 三、一期（Windows）做了什么

1. `export_presets.cfg` 加「Windows 验收」（调试，带 `tests/`、带控制台包装 exe）和「Windows 发行」（排除 `tests/`），x86_64，exe 旁边放同名 `.pck`（不嵌入，便于以后只换内容），不签名。模板用已装好的 4.7.2 Windows 模板（10-12 装，校验过）。
2. 全屏组合键按平台：`WindowFit.fullscreen_uses_meta`（`static var`，默认 `OS.has_feature("macos")`），`fullscreen_modifier_key()`、`fullscreen_modifier_held()`；`ui_smoke`、`xiyou_flow` 两种写法都测，不看测试机是什么平台（云端 Linux 上也成立）。
3. `导出冒烟.py --platform windows`：导出「Windows 验收」→ 只读检查 PE 头（x86_64、图形界面）、`.pck` 文件头、控制台包装 exe → 把这个 `.pck` 硬链接到 macOS 调试模板旁（同名；导出模板不认 `--main-pack`，只认可执行文件旁的同名 `.pck`），在隔离 HOME 里跑 `xiyou_mac_export`、`xiyou_flow`。本机不跑 exe。验的是「Windows 包里的内容和资源完整、能跑通流程」，Windows 上引擎本身的行为（DPI、输入法、全屏）要实机。

Windows 实机要看的（没有 Windows 机器，本机覆盖不了）：exe 能双击启动、窗口大小与高 DPI、Alt+Enter／F11 全屏、中文输入法（取名等）、存档在 `%APPDATA%\KYO\…`、杀毒误报与 SmartScreen 提示。

## 四、二期（安卓）设计

前提：本机要有 JDK 17、安卓命令行工具（`build-tools`、`platform-tools`），还要接受安卓 SDK 许可协议（`sdkmanager --licenses`）。导出模板已经有（`android_debug.apk`、`android_release.apk`）。不用 Gradle 构建（不需要 `android_source.zip` 和整套 Gradle），除非要写原生插件。

1. **导出预设**：「安卓 验收」（调试签名，带 `tests/`）、「安卓 发行」（排除 `tests/`），arm64-v8a，横屏（`screen/orientation` 横屏），包名另取（不和原版 `com.kyo.zaishuayiba157` 冲突，免得覆盖装掉原版存档），最低系统按 Godot 4.7 默认。发行签名用 Kyo 自己的 keystore，不进仓库。
2. **平台模块** `core/platform.gd`：`is_mobile()`、`is_touch()`（`DisplayServer.is_touchscreen_available()`）、存档导入导出、返回键、前后台；平台判断只从这里走，别的文件不直接 `OS.has_feature`。
3. **虚拟按键层**（`scenes/` 下一个 CanvasLayer，只在触屏设备上出现）：左下摇杆（八方向，战斗菜单里只取一个轴，照原版）、右下确定／取消／跑步、右上「菜单」「隐藏按键」；按键转成 `Input.action_press/release`，切后台、弹窗时全部松开。设置页加「按键大小」「透明度」「地图点按移动」「战斗点按」四项。
4. **返回键**：转 `ui_cancel`；标题画面问是否退出。
5. **前后台**：切后台暂停、松键、存一次设置；不做后台挂机（要原生前台服务，单独问 Kyo）。
6. **存档**：应用私有目录；设置页「导出存档／导入存档」走系统文件选择器（`DisplayServer.file_dialog_show`），导入前校验格式、先备份。
7. **验证**：导出冒烟加 `--platform android`：apk 结构（`AndroidManifest`、`assets/` 下 pck、arm64 库）只读检查，pck 同样放到 macOS 模板旁跑；有真机或模拟器时再用 adb 装和截图。
8. **分辨率**：先保持 1280×720＋`keep`（两边黑边），等虚拟按键能放进黑边后再评估 `expand`。

## 五、二期（安卓）做了什么（cc BH 2026-11-05）

总装 14:55 定（Kyo 09:21 授权）：发行版存档目录去掉「_开发」、安卓后台挂机照原版做且默认开，都做成开关。

1. 本机：JDK 17.0.21（`~/Library/Android/jdk`）、安卓 SDK（`~/Library/Android/sdk`）；引擎便携设置里填了 Java 路径，调试签名是 Godot 的调试 keystore（`引擎/…/editor_data/keystores/debug.keystore`，CN=Android Debug，不进仓库）。没建、没碰正式签名证书。
2. 预设「安卓 验收」（调试，带 tests/，包名 `local.kyo.remake.verification`）、「安卓 发行」（排除 tests/，包名 `local.kyo.remake`，正式签名留空，要 Kyo 自己的 keystore 才能导出发行包）。arm64-v8a、不用 Gradle、沉浸全屏、只要 WAKE_LOCK 权限；包名不和原版冲突。
3. `project.godot`：`window/handheld/orientation=4`（传感器横屏，导出成 userLandscape）；`config/custom_user_dir_name.release="KYO/再刷重制"`（O-待定：发行包存档目录去掉「_开发」，调试与编辑器仍是「_开发」；回退＝删这一行）。
4. `core/platform.gd`（XPlatform，GameApp 下）：两指点按转右键（游戏里 35 处右键＝取消，与 MV TouchInput 同一路），第二指本身不往下传；返回键＝取消，入口菜单上退出；切后台松开虚拟键；挂机中不锁屏。
5. 后台挂机（O-待定，`XPlatform.BACKGROUND_IDLE`，默认开）：Godot 切后台主循环就停，原版的前台服务要写安卓原生插件和 Gradle 构建。现在的做法是挂机中切后台、离开 5 秒以上，回来时把离开的时间按 8 倍速补跑（物理帧率与 time_scale 一起乘，同测试快进），最多补 30 分钟游戏时间，点屏幕停止、挂机停了也停。关掉＝切后台就停。和原版的差别：后台不会真的跑，系统可能把后台的游戏杀掉；没有通知栏常驻。要做到和原版一样，下一期写原生前台服务插件。
6. `core/touch_controls.gd`（XTouchControls，只在触屏设备出现）：左下摇杆（只取一个轴，中心 16% 不动）、右下确定／取消／跑步（跑步＝按住 Shift）、右上隐藏／显示按键（记在 `user://touch_controls.json`）；按住照 24／6 帧连发；按到按键的触点和它转出的鼠标事件都吃掉，不会点穿到地图，也不算两指取消；挂机补跑时屏幕中间显示剩余时间。
7. `导出冒烟.py --platform android`：apksigner verify、aapt2 看包名／arm64-v8a／横屏、包内关键文件；把 apk 的 assets/ 用 `打包pck.gd` 打成 pck，放到 macOS 调试模板旁跑 `xiyou_mac_export`、`xiyou_flow`。
8. 测试：`tests/xiyou_platform`（桌面上用 `XPlatform.force_mobile` 当成手机）。

滑动与长按：原版二合一包没有自己的手势，靠 MV 的 TouchInput（第一指＝鼠标：按住拖动列表、按住连续触发）；重制这边第一指照 Godot 的触屏转鼠标，走的就是桌面上已经照 MV 做的鼠标处理，所以没另写，要实机确认手感。

还没做（三期或实机后）：按键大小、透明度、位置调整；设置页的触屏选项；存档导出／导入；刘海安全区；真机帧率。

## 需要定的

- 安卓后台挂机要不要做到和原版一样（真在后台跑、通知栏常驻）：要写原生前台服务插件、改用 Gradle 构建。
