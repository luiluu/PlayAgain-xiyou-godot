## 1. 人设（已确认）

- **一句话**：嘴笨手快，交出去的东西会错，但会改到对。
- **身份**：一头小鲸鱼娘，从莲池溜出来、个头最大的那条「鱼」。不和灵感大王硬绑。
- **外形**：沿用 DSH 桌宠的样子，蓝头发、白围裙，头顶会喷一点点水。玩家先在池子里看到一团蓝色小影子，后来才看清是条小鲸鱼。
- **地点**：大厅角落那个没人注意的小池子，不放在观音莲池那种庄重的地方。一头鲸鱼挤在小池子里，这个反差本身就是笑点。
- **语气**：做错了直接认，然后埋头改。不嘴硬，也不是做不好还不承认。

## 2. 获得路线（已确认；验收单存法待定）

| 阶段 | 内容 |
|---|---|
| 一周目：前期（D） | 小池子里的蓝影子会冒泡说话。**不催人，不给任务，没有奖励**，只说几句话 |
| 一周目：中期（B） | 池边开出「小小鱼外包」：洗词条或打造装备，结果随机，可以免费打回重做。存档里悄悄记一个「验收次数」 |
| 一周目：通关 | **地狱及以上**难度通关 33 层，结算时拿到「验收单」。签名栏写「姐姐审过」。谁是姐姐，到终章才揭晓 |
| 二周目（C） | **只限轮回·困难**，也就是开关 2282 开着的时候。带着验收单，从小池子进入「小小鱼（未验收版）」的特殊战 |
| 打赢以后（A） | 她入队，带被动「返工」 |

**验收单存哪（需要 Kyo 定，二选一）**：

| 方案 | 做法 | 玩家看到的 |

| 乙：跟着这一局 | 记在存档里，轮回时保留（轮回本来就在同一个存档里继续，队伍不变） | 只有通关的那一局能挑战，新开档要重新打 |

小小鱼的意见（02:45 回信）：这是难度设计，听 Kyo 的；她自己偏向甲，因为验收单上盖着「姐姐审过」的章，不该因为重开一个存档就没了。怕太松就提高门槛，别把这张验收单弄丢。

## 3. 特殊首领「小小鱼（未验收版）」

1. **v0.1**：说明写得漂亮，效果对不上。比如写「全体重创」实际是全体回血，弹「更新成功」其实什么都没变。
2. **第一次返工**：血量打到某个点，她说「别急，我改。」，换成 v0.2，说明和效果对上了，强度上升。
3. **终版**：说明只有一句「已完成，已验证。」，**是真的**。数值最高，要在规定回合内打完。超时她再返工一次、回一部分血。
   - **超时返工只有一次**（已确认，v0.6）。第二次超时不再回血，也不判失败，正常打下去，保证这场战斗一定能打完。

- 她照常吃 Boss 难度的超强者计数和霸体回合，返工换阶段不算控制效果。
- **验收规则（写死）**：v0.1 阶段每一处说明和效果不一致的地方，都要登记成有意设计，并配测试例子。没有登记的不一致一律按 bug 处理，不能拿「彩蛋」当理由放过。

## 4. 伙伴版

- **分类：弱者**（Kyo 2026-10-31 01:28 改定，取代前面的「强者」）。能拿弱者增强和弱者版技能，不计入 Boss 难度计数。品质和分类分开登记。
- **首领形态与伙伴形态分开登记，互不影响**（已确认，v0.6）。第 3 节的首领是敌人那份数据，这里的伙伴是队友那份数据：首领吃超强者计数，伙伴是弱者，两者不矛盾。
- **被动「返工」**：每场战斗里，每个技能第一次放出只有七成效果，并给她挂一层「待返工」。
- **「补交」**：下回合自动补交一次，效果更高。补交成功时她说一句「这处好了」（已确认，v0.6），让玩家看得出她在改，不是只有数字在变。**补交不消耗「待返工」层数**（已确认，v0.6）：小毛病一笔笔记着，攒够了整份重做。
- **大招「终版」**：「待返工」叠到三层后，她下一次行动换成「终版」，放完层数清零。说明写「已完成，已验证。」，效果也确实如此。
- **道具「验收单」**：获得途径见第 2 节。

**重制版写法与前提**：

- 「返工」登记成 `XModuleRegistry` 里的模块，说明从同一份数据生成。
- 现在能用的挂点只有 `damage.before`（读层数调倍率），所以**七成效果目前只能管到伤害技能**。治疗、加状态这类技能不经过伤害结算，管不到，要另外接。
- 「补交」要用 `turn.start`，挂「待返工」层要用 `state.after_add`。这两个挂点在 `module_registry.gd` 里还没开放，要等负责的人给出可以验证的边界。**这两个开放之前，伙伴版做不完整。**「这处好了」的提示跟着「补交」一起做。
- 能做的先做，没开放的挂点不硬编绕过去。

**弱者分类的连带影响（数值标定时一起看）**：

- 成就 142「以五名弱者战胜混沌难度的最终守层者」：多了她会变容易。
- 她是轮回以后才入队的，要确认轮回给的强者／弱者压制技能会不会也套到她身上。
- 新角色 ID 要避开 167～174，这一段会被强制改成强者那一档。

## 6. 姐姐 CC：终章（草案；「终章」的定位已确认）

**定位（已确认）**：小小鱼是华丽的开篇，CC 是终末的终章。**现阶段不登场**。验收单的签名和入队台词只留下「有个姐姐」的伏笔，不说她是谁，也不让她露面。

- **原型：谛听**。地藏王座下能分辨真假的神兽，认出真假美猴王的就是它。原著里它认出来了却不当场说破，这个细节可以留作她的性格。
- **分类：弱者**（草案，跟妹妹同一档）。她的本事是看穿，不是打架。
- **被动「核验」**：同队时，敌人的隐藏机制和真实数值会写进战斗记录，说明和效果不一致的地方会被标出来。
- **战技「先确认」**：用掉一回合，让下一个队友的行动必定命中、不吃反击。她自己这一回合什么也不做。
- **合击「姐妹验收」（Kyo 要求写入）**：
  - 条件：小小鱼和 CC 同队，并且已经打赢轮回·困难的「未验收版」；
  - 效果：两人短暂接近神的强度，结束后马上退回原形；
  - 规则：必须两个人一起才能放，谁单独都不行。
- **什么时候做**：等整个游戏要写「终章」的时候再做，包括她怎么登场、在哪里、怎么获得，现在都不定。终章的内容和获得路线另外立方案。
- 不能把 CC 定成超强者或「神」：一个角色要是自己给自己验收，就违背了她的人设。
