# 云端测试（Claude 云端会话）

云端容器没有本机的 Godot.app、转换产物和冻结正式源。用 `云端准备.sh` 补齐前两样后，Godot 测试与 `检查.sh` 能在云端跑；`--oracle` 和探针仍只能在 Mac 上跑（要冻结正式源）。

## 步骤

1. 取转换产物（`modes/xiyou/generated/`，不入 Git）：在连了 Mac 文件夹的会话里，在 Mac 主工作区打包到 `.git/` 下（不进 `git status`，不挡合并）：
   `cd 03_再刷重制_Godot/01_Godot工程 && tar -czf ../../.git/cloud_generated.tgz modes/xiyou/generated`，
   再把它传进容器（或放进项目文件夹 `/mnt/project-files/云端测试/generated.tgz`，以后的云端会话直接用）。用完可在 Mac 上删掉 `.git/cloud_generated.tgz`。
2. `bash 03_再刷重制_Godot/07_开发环境/云端准备.sh [打包路径]`：装 zsh，下载与[环境登记](./环境登记.json)同版本的官方 Godot Linux 版并校验 SHA512，解开产物，`--import`。最后一行是要 export 的环境变量。
3. `GODOT=… CHECK_JOBS=4 zsh 03_再刷重制_Godot/07_开发环境/检查.sh`（`检查.sh` 的 GODOT 可用环境变量覆盖）。

## 2026-10-18 首次实测

- 转换产物取自 Mac main（sync_stamp 2026-10-18T02:05，v0.28 测量不变），打包 192 MB；Godot 4.7.2.stable.official.ed1daf0bf，与 Mac 同一构建。
- Godot 测试 65/65 通过，4 核约 5 分 16 秒；参照守卫、共性验收、合并工具、内容覆盖等工具检查全部通过。
- 「文档与登记」一节在云端会报 49 条失效链接，都指向不入 Git 的本地文件（`04_验证/本地结果/`、`验证与备份/`、`02_再刷西游/现有资料库`、`当前Godot.app`、`/Users/...`），属环境差异，不是问题。
- 产物会随车道合并过期：同步过的分支要重新打包。
