# 美术统一工具（原型）

解决「角色行走图每次出图质量不稳」的工具。图片不进仓库，路径都从命令行给；这里只放脚本、素材档和配方。

## 生成器.py：行走图角色生成器

照 RPG Maker 角色生成器的思路，部件全是自己的：把已定稿的行走图拆成部件存进本地部件库，之后按配方选部件、换色，一条命令导出 144×192 的 `$` 行走图。

| 子命令 | 做什么 | 例 |
| --- | --- | --- |
| `拆件` | 把一张定稿行走图拆成头（光头＋脸）、发、身体三类部件入库 | `python3 生成器.py 拆件 五条悟.png 素材档/五条悟v2.json --名 五条悟 --库 <部件库>` |
| `导出` | 按配方拼部件、换色，导出行走图 | `python3 生成器.py 导出 配方/生成器示例_黑发红眼灰衣.json 输出.png --库 <部件库>` |
| `总览` | 把部件库排成一张图 | `python3 生成器.py 总览 --库 <部件库> --输出 一览.png` |

- **部件**：头和发各四张（下、左、右、上），身体是脖子以下 12 帧，并记着每帧头该放在哪。同一方向的三帧共用同一张头和发，只跟着身体平移，所以走路时头不会一帧一个样。
- **光头**：拆件时在头发底下补一块头皮，换上别的发型不会露洞。
- **素材档**（`素材档/*.json`）：告诉拆件怎么认这张图，肤色和眼睛的颜色范围、四个方向脖子离脚底几行、身体怎么分成上衣、下装、鞋。每张源图写一份。
- **配方**（`配方/生成器示例_*.json`）：`头`、`发`、`身体` 各填一个部件名；`换色` 里按 `发`、`眼`、`肤`、`身体.<分区名>` 给色带（从暗到亮）和描边色，不写就保持原色；`发偏移` 可按方向微调发型位置。
- 同样的部件库和配方，导出结果逐字节相同。

## 行走图.py：体检和预览

| 子命令 | 做什么 | 例 |
| --- | --- | --- |
| `体检` | 量一张行走图，和基准图比；有一项不合格就退出码 1 | `python3 行走图.py 体检 新图.png --基准 五条悟.png 原版角色.png` |
| `预览` | 几张行走图并排放大成一张对比图 | `python3 行走图.py 预览 a.png b.png --输出 对比.png --字体 <中文字体>` |
| `换装` | 第一版原型：整张模板直接换色。已被生成器取代，留着备查 | |

体检量的项：头占身高比例、头宽、人物高、每格颜色数（每通道归 16 档）、内部细节量、死黑线占比（外缘近黑而里面紧挨亮色的点）、空格、各格高度差、脚底行差、贴边、半透明像素。基准范围取几张基准图的最小到最大再放宽，规则表在脚本里的 `规则`。

## 现在的限制

- 只做了行走图。战斗图（9×6 格 54 帧）要先解决每个动作的头部定位和表情，还没做。
- 部件库现在只有五条悟 v2 和宿傩 v2 拆出来的两套。新发型、新衣服要先有一张图（Codex 画或手画）再拆进来。
- 头和身体是按脖子那一行横着切开的，披到肩膀以下的长发、高领围巾这类跨过脖子的东西还处理不了。
- 走路的左右两步用的是站立帧的头，和原图比每格约有 600 个像素不同；站立帧和原图只差 0 到 7 个像素。
- 体检量的是比例和层次，量不出「像不像这个角色」，这一项还得人看。
- 没有图形界面，现在是写配方文件加一条命令；也还没有单元测试，没接进 `检查.sh`。
