# 美术统一工具（原型）

解决「角色行走图每次出图质量不稳」的工具。图片不进仓库，路径都从命令行给；这里只放脚本和配方。

## 行走图.py

| 子命令 | 做什么 | 例 |
| --- | --- | --- |
| `体检` | 量一张 `$` 行走图（3×4 格），和基准图比；有一项不合格就退出码 1 | `python3 行走图.py 体检 新图.png --基准 五条悟.png 原版角色.png` |
| `换装` | 拿基准行走图当模板，按配方换色、加腰带和脸纹，再叠可选图层，生成新角色行走图 | `python3 行走图.py 换装 五条悟.png 配方/示例_粉发赤膊.json 输出.png [--图层 发型.png]` |
| `预览` | 几张行走图并排放大成一张对比图 | `python3 行走图.py 预览 a.png b.png --输出 对比.png` |

体检量的项：头占身高比例、头宽、人物高、每格颜色数、内部细节量、外缘近黑描边占比（只设上限）、空格、各格高度差、脚底行差、贴边、半透明像素。基准范围取几张基准图的最小到最大再放宽，规则表在脚本里的 `规则`。

换装的做法：模板每格按颜色和位置分成发、眼、眼白、肤、上衣、下装、鞋七个区；每个区按模板原来的明暗换到配方的色带上，所以身形、脸、步态、明暗层次都原样继承模板。同样的模板和配方，输出逐字节相同。

- `配方/模板档_五条悟.json`：怎么给五条悟行走图分区（肤色和眼睛的色相范围、四个方向脖子离脚底几行、上衣和鞋占身长多少）。换模板图就另写一份。
- `配方/示例_粉发赤膊.json`：示例配方。色带从暗到亮；`均衡` 用在模板那一区大半是同一档亮度时（白发）。

## 现在的限制

- 只做了行走图。战斗图（9×6 格 54 帧）要给每个动作标脖子位置，还没做。
- 发型和衣服的外形还是模板的。要换外形，画一张和模板同尺寸的透明图层，用 `--图层` 叠上去，再跑体检。
- 体检量的是比例和层次，量不出「像不像这个角色」，这一项还得人看。
- 还没有单元测试，也没接进 `检查.sh`。
