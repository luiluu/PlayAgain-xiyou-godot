# 虚拟玩家

一个替人把流程玩一遍的机器人（Kyo 2026-11-13）。走路、对话、战斗、换装只靠按键和鼠标点击（和真人操作走同一条输入路径），所以它走到的地方就是玩家按得到的地方；卡住、按键没反应、界面关不掉、脚本报错这类问题会被它撞上。养成里不值得逐键点的几样（宝珠鉴定与镶嵌、种族进阶、买副本符文、抽奖的数量框）直接调菜单背后的同一个函数，条件和消耗照游戏的来。

Kyo 确认的目标：像正常玩家一样把整个游戏通关，用来替他测试；bug（卡死、报错、流程不通）和平衡问题（太难、数值不合理）都要抓；放在 GitHub Actions 上跑。

- 机器人：`01_Godot工程/tests/virtual_player/virtual_player.gd`；直接调逻辑的养成在同目录 `vp_growth.gd`
- 专项与命令行入口：`01_Godot工程/tests/xiyou_virtual_player.gd`／`.tscn`
- 云端：`.github/workflows/virtual-player.yml`（Actions 页叫「虚拟玩家」）

## 两种玩法

- **逛图**（默认，`explore`）：开新局，在大厅一带逐个调查事件、点开菜单子页随手按几下、用传送页换地图，遇到战斗手动打、打不动就逃跑。全量检查里跑的是这个（三十秒左右）。
- **爬塔**（`--vp-mode=climb`）：照玩家的打法往上通层。
  1. 大厅：没选族先去门口的种族向导选族；队伍掉血了找会治疗的 NPC；做养成（见下一节）；按 `~` 存档；去塔门选「进入该层」。
  2. 塔里：找这一层的守层者选「挑战」。战斗先手动按几步，再用鼠标点战斗左上的「自动」按钮，交给游戏自己的自动战斗。
  3. 打赢（层数加一）：按 `1` 回大厅，进下一层。通过第 5 层后大厅会出天启篇选线，它选第一张能选的卡并确认。
  4. 全灭：结束画面按确定回标题 → 「旧的回忆」读档 → 回到塔里按 `G` 挂机练级（第一次 6 场，之后每输一次翻倍）→ 回大厅 → 去刷这一层的副本首领（第一次 2 次，之后每输一次再加 2 次）→ 再挑战。
  5. 同一层输满 5 次、或连着三轮找不到守层者，就收工并写明停在哪一层、为什么。

## 养成（照游戏内「商店向导 → 下一步建议」写的路线）

| 做什么 | 怎么做 | 什么时候 | 关掉 |
| --- | --- | --- | --- |
| 换装备 | 按键：菜单 →「装备」，逐人逐槽比属性 | 大厅里背包装备有变化时 | `--vp-no-equip` |
| 刷副本首领 | 按键：楼层地图上的副本入口选「挑战副本」「普通难度」（要重置先选「重置副本」）→ 副本里清挡路的小怪、往里走、打首领 → 再调查首领领奖被送回楼层 → 回大厅治疗存档。符文按商店标价直接买（大厅阿卡拉卖，标价 0） | 输给守层者之后；`--vp-farm-first=N` 改成每到新一层先刷 N 次 | `--vp-no-farm` |
| 真气突破 | 调 `map.run_zhenqi_retreat()`（同菜单「真气」），对话和选项照常按键：有奖励先领（选攻击属性／全属性），能突破就打瓶颈之战 | 大厅里出战的人有奖励没领、或真气够且楼层门槛已过 | `--vp-no-zhenqi` |
| 宝珠 | 直接调：领暂存 → 神秘珠全部鉴定 → 出战的人装备上的空孔镶阶位最高的可镶宝珠 | 每次打过仗回大厅 | `--vp-no-orbs` |
| 种族进阶 | 直接调：领暂存 → 有下一阶进阶石就逐阶进阶 | 同上 | `--vp-no-race` |
| 抽奖 | 按键走到希禾选「自定义单抽」，数量框代填最多 | 大厅里有抽奖券时 | `--vp-no-lottery` |

- 在副本里全灭不算守层者的失败；同一层的副本首领输 2 次，这一层就不再去刷（小结里写明）。
- 副本入口不在楼层主图上的层（如第 3、5 层在支线地图里）它现在找不到，小结里写「地图 N 上没有副本入口」。

## 本机怎么跑

```bash
cd 03_再刷重制_Godot
# 爬塔 20 分钟，报告写到 /tmp/vp
07_开发环境/godot --headless --path 01_Godot工程 -s res://tests/test_main_loop.gd res://tests/xiyou_virtual_player.tscn -- \
  --vp-mode=climb --vp-minutes=20 --vp-seed=1 --vp-out=/tmp/vp --vp-verbose
```

- `--vp-floors=<层数>`：通过这么多层就收工（没通过算失败）。
- `--vp-seed=<数>`：种子。开局阵容、通关抽角色的候选、战斗和掉落的随机都跟着它走：同一个种子两局的阵容和每场战斗的结果一样（帧数会差一点）。`--vp-loose-random` 关掉，每局都不一样。
- `--vp-frames=<帧数>`：玩这么多画面帧就收工。无头模式一帧就是一个游戏逻辑帧，所以它等于「游戏里过了多久」（150000 帧约 42 分钟），不受机器快慢影响；做前后对比用它，别用 `--vp-minutes`。
- `--vp-tag=<字>`：同一个种子同时跑两局时给存档目录加后缀，免得互相读到对方的存档。
- 调试用（小结里会标「调试局」）：`--vp-debug-floor=<层>` 开局直接把层数改成这一层；`--vp-debug-items=物品号:数量,…` 开局直接给物品（验证养成的代码路径）。
- `--vp-out=<目录>`：写 `report.json`（完整报告）和 `summary.md`（给人看的小结）；窗口模式下每次换画面截图。
- `--vp-verbose`：打印每一步的目标和画面变化。
- 去掉 `--headless` 可以看着它玩（`--vp-speed=<倍数>` 调快慢，默认 4）。
- 存档和设置写在独立的测试目录（`user://test_virtual_player/<种子>`），跑完删除，不碰真实存档。

## 云端怎么跑

- Actions 页「虚拟玩家」→ Run workflow：填种子（每个种子一台机器，各玩一局）、每局分钟数、要通过几层。
- Run workflow 里的「额外参数」原样传给机器人（如 `--vp-no-farm`、`--vp-frames=150000`）。
- 定时（每天一次）写好了但先关着：机器人还不会花钱，眼下多数阵容停在前几层并判红。要开就把工作流里 `schedule` 两行的 `#` 去掉。
- 分支上试改动：`git push github HEAD:refs/heads/vp/<名字>`，用默认参数跑这个提交；看完删掉这个分支。
- 结果在运行页摘要：每个种子一段小结（爬到第几层、收工原因、全灭次数、练级场数、卡住与存疑、每层一行的表）。完整报告和日志在附件 `vp-seed-<种子>`。

## 什么算红

| 情况 | 结果 | 意思 |
| --- | --- | --- |
| 机器人卡死（画面长时间不变，自救三次无效） | 红 | 多半是游戏卡住或某个界面按键出不去，报告写明卡在哪个画面 |
| 同一句对话在同一个位置重复 80 次 | 红 | 对话在兜圈子出不来（可能是游戏的问题，也可能是机器人总选到「再想想」这类选项），报告写明是哪一句 |
| 日志里有脚本报错 | 红 | 游戏代码出错 |
| 金币或生命为负 | 红 | 数值出错 |
| 爬不动：同一层守层者输满 5 次，或找不到守层者 | 红 | 要人看：可能是这层太难、养成没用，也可能是机器人不够聪明（见下）。小结里「没打赢的战斗」写着每场差多远 |
| 时间用完 | 绿 | 小结里看爬到了第几层 |
| 「存疑」（如生命高于上限） | 绿 | 列在小结里给人看 |

## 它还不会的（红了先排除这些）

- **不会花钱**。大厅商店里的饰品和「至臻」装备、战技书与精通书、功法、丹药，抽奖攒下的肝帝积分能换的东西，它都不买；一局下来金币十几万到二十几万、积分几千都没动。这是眼下最大的短板，养成跟不上的层它会停在那里，这种红不一定是游戏的问题。
- 不会学技能、吃药、配被动、用宠物；通关抽角色和天启篇选线只会选第一个能选的。
- 战斗只会「手动攻击几步 → 点自动」；需要特定打法的首领它打不过。打到 40 回合还分不出胜负算僵局，按游戏结束认输后读档。
- 副本入口要在楼层主图上，或主图有门直接通到有入口的那张图；再深一层的它找不到。
- 守层者不在进门那张图上时，只会在附近逛着找，找不到就回大厅重来。
- 七印祭坛这类分支，它只会按「没选过的优先」去试选项。
- 存档时有人倒着：大厅三位治疗 NPC 轮流找（老妪十分钟才治一次、阿卡拉限 50 次、贪财老妪收精魂），都没治好就带伤上，里程碑里记 `saved_hurt_<层>`。

改机器人的入口：认画面在 `observe()`，各画面的打法是 `_act_*`，爬塔的决策在 `_act_climb`／`_climb_lobby`／`_climb_floor`，副本在 `_go_dungeon`／`_climb_dungeon`，闭关的选项在 `_zhenqi_choice`，直接调逻辑的养成在 `vp_growth.gd`。

## 小结里怎么看平衡

- 「没打赢的战斗」列出每场全灭或僵局时敌人开打的血、收工时剩的血、打到第几回合。打掉不到一成说明差得远，不是多练几场能补上的。
- 「副本首领（倒／进／灭）」一列是这一层打倒几次、进了几次、在里面全灭或僵局几次；「第 N 层不再刷副本：……」写明为什么放弃。
- 「养成」「宝珠」两行是收工时的真气、境界、抽奖券、肝帝积分、镶了几颗宝珠、种族阶位和手里的进阶石。

## 读代码查到的养成门槛（红了对照着看）

- 真气突破第一关（筑基）要真气 600 并且先通过第 5 层，之后每一关再加 5 层；重制版里真气的加成只显示、不乘进伤害，所以前五层攒真气本身不会变强。
- 副本要从普通一档档打上去：打赢已开放的最高一档才开下一档，开到「王者」那一页，首领才开始给抽奖券、熟练度奖励、神秘珠（每场一成）和种族进阶石。也就是同一个副本至少要赢三次才有这些。
- 种族进阶石只有 7 层及以上的副本首领给。
- 天启篇里副本选哪一档，敌人的血量和攻击倍率都一样（倍率只认本档难度），不像原版普通档低很多。
- 抽奖赌的是肝帝积分，不直接给战力；积分要拿去商店换东西。

## 2026-11-13 首次实测

- 云端（推 vp/trial 触发，三个种子各一台 2 核机器，准备 2 分钟、命中「云端选测」的导入缓存）：种子 1 和 3 通过第 1 层、停在第 2 层守层者；种子 2 通过前四层、停在第 5 层守层者，用了 16.7 分钟。三局都按「爬不动」判红。
- 本机（M1 Pro，无头约每秒 500 帧）：三个种子各五分钟上下，都通过第 1 层、停在第 2 层。另一次连第 1 层都没过。
- 停下的原因一样：等级到本层上限（1 层 10 级，之后随通层上调）后挂机练级不再变强，机器人又不会配装备和学技能。开局随机到的五个人强弱差别很大，决定了能走多远。
- 加了换装之后再测（本机三个种子各 8 分钟）：每局去装备页四五次、换上十几到几十件装备，仍然是一局没过第 1 层、两局停在第 2 层。第 1 层守层者七百万血、第 2 层七千万血，队伍十级加基础装备撑不到打完。游戏内向导写的正常路线是：反复刷副本首领拿真气和抽奖券 → 菜单「真气」突破 → 宝珠坊、种族进阶 → 再打守层者。这条养成路线是下一步要教它的。

## 2026-11-13 养成路线实测（随机固定后，三个种子各玩 150000 帧，约 42 分钟游戏时间）

| 种子（开局阵容） | 不养成（只练级、换装） | 加刷副本首领、闭关 | 再加宝珠、种族进阶、抽奖 |
| --- | --- | --- | --- |
| 1（90、76、150、35、30） | 停在第 5 层（输满 5 次） | 第 5 层，时间用完；打倒副本首领 10 次，抽奖券 53 张 | 第 5 层，时间用完；副本首领 8 次，抽奖 26 次，积分 8240 |
| 2（3、22、19、76、32） | 停在第 1 层（输满 5 次） | 停在第 1 层；副本首领普通档也打不过 | 同左 |
| 3（43、25、88、83、42） | 停在第 2 层（输满 5 次） | 第 2 层，时间用完；副本首领 8 次，抽奖券 34 张 | 第 2 层，时间用完；副本首领 8 次，抽奖 26 次，积分 3451 |

- 结论：照游戏内向导的路线养成之后，同样的游戏时间里三局都没有多爬一层。能走多远主要看开局随机到的五个人。
- 没用上的：真气突破（没人过得了第 5 层守层者，门槛没开）、宝珠（三局一颗神秘珠都没掉）、种族进阶（进阶石要 7 层以上）。用上的只有副本首领的装备和抽奖券，抽奖换来的积分它还不会花。
- 差多远：种子 2 的阵容十级、练了 90 场，对第 1 层守层者（700 万血）12 回合只打掉 2%～3%；种子 3 对第 2 层守层者（7000 万血）打掉一到两成；种子 1 对第 5 层守层者（5.3 亿血）两到四回合全灭、打掉一成多。
- 种子 1 的阵容打第 1 层副本首领（210 万血）两次都打成僵局：40 回合后首领还是满血。
- 这一轮顺手修掉的机器人自己的问题：选项窗还在展开就按键（天启篇选线的确认框因此一直选不上）、对话兜圈子看门狗看不出、只认一位治疗 NPC 导致一直带伤上场、上一局被杀掉后留下的存档被下一局读走、副本里去惹首领倒下后才出现的隐藏对手。
