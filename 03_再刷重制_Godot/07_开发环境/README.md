程序来自 Godot 官方发布，标准版使用 GDScript。Mac Universal 包兼容 Apple Silicon 与 Intel，本机已实际运行。

| 位置 | 内容 |
| --- | --- |
| `引擎/4.7.2-stable/Godot.app` | 官方应用，未修改包内文件，签名及 Gatekeeper 检查通过 |
| `引擎/4.7.2-stable/_sc_` | 包外便携标记，保持应用签名 |
| `引擎/4.7.2-stable/editor_data` | 编辑器配置、缓存和模板入口；已验证便携模式 |
| `导出模板/4.7.2.stable` | 与编辑器版本匹配的官方模板原件，通过链接供编辑器使用 |

| `godot` | 本库命令行入口，传入原生 Godot 参数 |

只有一份当前引擎和一份同版本模板原件。`当前Godot.app` 与编辑器模板入口为链接；升级时先保留旧登记，核对新版本与匹配模板、验证工程后再切换链接，不自动更新正在使用的版本。

已验证官方下载校验、签名、版本、正常编辑器初始化/退出、便携路径，并查看实际项目管理器窗口。将来 Windows/Android 导出还要配置各平台所需工具与签名，模板安装不能替代实机验收。

本轮备份与完整成功/失败记录见[部署验收目录](../../00_项目管理/验证与备份/20261012_Godot部署/)。下载包、引擎、模板和缓存不进入 Git；维护入口与版本登记进入 Git。

## 共用工具

- `检查.sh [--oracle]`：提交前检查。验证 JSON、文档链接、开发编号三处一致，运行 `01_Godot工程/tests/` 下全部测试（任何 `ERROR:` 都算失败），可选启动 MV 参照引擎。
- `开发编号.py`：不带参数时显示开发编号；`bump "说明"` 递增编号，并同步 `开发编号.json`、`project.godot` 与 `build_info.json`。
