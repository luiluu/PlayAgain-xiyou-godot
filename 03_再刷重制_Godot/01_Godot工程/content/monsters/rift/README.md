# 西游档战斗异化模板

人形 `humanoid`、鳍骨 `finbone`、岩壳 `rockshell` 对应瑟伦、鱼人士兵、黝石巨人之影三个原尺寸样本。三个模板的侵染沿表面蔓延，蚀骨从同一处裂开，化形沿裂口长出折肢。岩壳素材包含 T504 的立体脊节、近远肋骨与加粗的两条长肢。

| 阶段 | 贴图 | 合成位置 |
| --- | --- | --- |
| 侵染 | `qinran/stain.png` | 身体前，按身体透明度裁切。紫黑洗色为部分透明，脉络为硬边。 |
| 蚀骨 | `shigu/bone_back.png`、`shigu/tear_front.png` | 后件在身体后吐出骨刺。前件在身体内铺断口与露出的骨，岩壳件留透明孔以露出下方原岩层。 |
| 化形 | `huaxing/limb_back.png`、`huaxing/root_front.png` | 后件撑出不对称长肢，前件把肢根接回蚀骨破口。按 `anchors.json` 叠加前级素材。 |

## 锚点与显示

- `anchors.json` 里的 `root_uv`、`avoid_uv_rects` 都以当前身体的非透明范围为基准。坐标原点在左上，屏幕为向右、向下递增。避让矩形用左、上、右、下表示。`root_px` 为贴图内的同一个根点，`offset_from_body_cell_px` 为相对样本原帧单元左上的偏移，可用于复现该例。实际怪物的根与避让区须随朝向翻转。
- 图层在原帧坐标上画，输出是 RGBA PNG，每边有透明余量。消费端用最近邻采样。模板跟随身体最终变换、可见范围和同一套等比缩放，遮挡、偏心和浮空按清单标记补锚点。技能动作不能用武器或过大裁切区拉长模板。大体形的肢端需给 HUD、屏边和邻怪留空间。
- `西游战斗怪模板清单.md` 按实际外观键分配模板，标记锚点例外。主表含西游切片敌群、战斗事件变身和冠军之路的运行时敌人。表格也保留冻结源候补。复用同一外观键可共用补锚点的工作。
- 以 `XRiftAlien.on(state)` 和已命中的 `tier` 限定西游档。`tier_color_hint` 是便于首轮接入调色的底色建议。侵染的局部覆盖由 `stain` 提供。没有适配素材时可回到当前偏色，保持原先的阶段和判定逻辑。素材还待接入卡落到战斗渲染路径，届时检查跟帧、退场、相邻怪物和天启篇隔离。
