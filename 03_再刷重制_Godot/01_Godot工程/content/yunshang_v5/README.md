## 指定参考与量测

- 谷雨定稿14d355606实际文件为交付归档续作/Guyu_Walk_refined.png（同提交content/guyu_v2文件不可直接取出），复制为Guyu_Walk.png。wait从同提交Guyu_Battle_candidate.png抽取。五条悟从定稿gojo素材取，原版云霄模板仍作动作与落脚参照。
- reference_measurements.json记录三套各15帧：头高、头宽、身高、肩宽、髻高，以及颈线和肩点。参考量表.png包含全部数值；reference_grid.png、参考标点.png保留原生放大与定位辅助。
- **定义及局限**：身高从正常头顶到最低脚底；髻高另列不计入头高。头高从正常头顶到下巴/颈线；头宽为该区域可见头发轮廓，参考图中的花饰、侧辫可能扩大轮廓，不能等同颅骨宽。肩点人工选择，排除垂发和手，衣袖/长发遮挡处有估计误差。背向颈线不可见，参考和新稿均是推定；新稿后颈按可见袖肩推定，源图约±20px即约1.5原生px不确定性。不能把这些手标代理值说成准确人体关节点门禁。
- source_landmarks.json为15个源帧的原图坐标标点。新稿标点.png在真实成品上画正常头顶黄线、颈线红线、肩段青线，供复核；alignment.json含源点、统一缩放系数、实际落点、逐项差值。坐标不是自动识别，需人工核量测口径。

## 处理方式

alpha>=128二值化；按alpha连续列切三主体、计数不符就报错。每帧**仅一个全身同比缩放系数**：遍历可容纳的原生高度，以头高、头宽、身高、肩宽四项相对谷雨的最大误差最小化，再以总误差择优。不分段缩头、扩身，不镜像、复制或补绘帧。云霄仅提供水平中点和脚底；不再把云霄宽度拼到谷雨头区。髻高单列，不用裁发髻藏差异。像素取整会有约1px差异；不同形状无法靠一个比例同时消掉所有差异，残差直接记录。

共享11色色表沿用已批准色系，从头像可见像素取色：白发/白衣#f4f2fa/#d8d4e8/#aba6c2/#77758c；肤色#ffe5d8/#d6a699；深蓝#222849/#3c426f；金#f0cb7b/#9d8245；描边#151726。所有帧强制映射同一表，不能每帧量化。背面用宽灰影分三大发束，蓝镶边和流苏保留。
