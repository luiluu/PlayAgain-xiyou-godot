# 玩家资料包的三份文字

`玩家资料包.py`（`07_开发环境/`）出包时把这里的 `更新记录.md`、`和旧西游的不同.md`、`常见问答.md` 原样拷进
`~/Documents/DSH/小小鱼/game/玩家资料包/v<版本>/`。

- 期一（T008）先放占位「（待补）」，不阻断出包；期零由小A 起草 `和旧西游的不同.md`、总装回填 `更新记录.md`，
  `常见问答.md` 等 Y2 拍板（小A 起草约 20 条，Kyo 或测试玩家改）。
- 只写玩家在游戏里看得到的东西：不写伤害公式、内部编号、路径、天启篇新篇章内容；**不写死任何版本号**。
- 掉率（X12，Kyo 11-16）：游戏说明卡或对白里原样写着的掉率可以照抄（要逐字一样）；游戏里没写的掉率一个都不写。
  出包自检②会把这三份里每一行掉率样式的句子拿去比本次取字抓到的玩家文本，对不上就整包不出。
- 改完不用另跑什么：下一次 `发布补丁.py --verify-online` 通过后自动出包，出包自检会对全文做禁词、编号与掉率句检查。
